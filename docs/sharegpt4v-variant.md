# 자세한 캡션으로 텍스트 SAE를 다시 학습하는 탐색 실험

COCO2017 학습 이미지 118,287장은 유지하고, 원래 캡션 591,753개를 ShareGPT4V 캡션 118,287개로 교체한다. 이미지마다 새 캡션 하나를 사용한다. 이미지 SAE는 기존 가중치를 유지하며 텍스트 SAE만 처음부터 다시 학습한다. 이번 주 발표 자료와 기존 결과는 수정하지 않는다.

입력 파일은 로컬의 `/Users/jihoonkwon/Desktop/projects/research/MM-SAE/mm-sae/asset/sharegpt4v_coco_train2017.json`이다. 서버에서는 `/mnt/working/mm-sae/asset/sharegpt4v_coco_train2017.json`을 사용한다. 이미지 목록과 픽셀 주석은 기존 COCO 파일에서 읽는다. 교체 파일의 이미지 ID가 모든 학습 이미지에 대응하는지 검사하고, 캡션마다 내부 ID를 부여한다. 교체 파일의 SHA-256 해시를 실행 기록에 남긴다.

HF CLIP 토크나이저에 `truncation=True, max_length=77`을 적용한다. 77토큰에는 시작·종료 토큰도 포함된다. 요약하거나 문장을 나누어 평균을 내지 않는다. JSON과 색인에는 원문을 보존한다. 텍스트 개념 유무와 가림 평가는 실제 입력에서 온전히 남아 있고 토큰 위치를 확인한 사전 표현만 사용한다. 잘린 뒷부분에 같은 표현이 다시 등장해도 앞부분의 표현은 가린다. 경계에서 단어 자체가 잘렸거나 토큰 위치가 불확실하면 해당 개념의 가림 표본에서 제외한다. 개념 주석은 사람의 의미 판정이 아니라 기존 사전에 따른 자동 주석이다.

텍스트 SAE는 기존과 동일하게 4,096개 좌표 중 8개를 활성화한다. 학습률 0.0005, AdamW, cosine 학습률 감소, 초기 5% 준비 구간, 배치 크기 1,024, 30회 반복 학습을 유지한다. 학습 캡션 수가 줄어 최적화 횟수는 3,480회다. 기존 캡션 수에서는 같은 설정으로 17,340회였다. 따라서 결과 차이를 배경 언급 증가만의 인과 효과라고 해석하지 않는다. 캡션의 서술 방식, 샘플 수, 최적화 횟수도 함께 달라지는 탐색 실험이다.

검증 이미지 5,000장에는 기존 COCO 캡션을 유지한다. 학습 분할에서 새 캡션의 상관점수를 관찰하는 분석과, 기존 검증 캡션으로 일반화되는지 보는 분석을 구분한다. 자세한 검증 캡션을 이용한 독립 평가라고 부르지 않는다.

서버의 `/mnt/working/mm-sae/configs/sharegpt4v-sequence.yaml`에 실행 순서를 정의했다. 데이터 준비, 임베딩 계산, 텍스트 SAE 학습, 개념별 가림과 특징 선정, 상관행렬 계산, 원본 RQ1 점수 분석, Greedy·헝가리안 분석을 실행한다. 이후 기존 RQ1·RQ2 후속 분석을 같은 코드로 실행한다. 양의 동시 등장 관계를 비중 조절로 제거한 비교는 기존 검증 캡션과 새 학습 캡션에서 각각 계산한다. 새 학습 캡션의 비교에는 학습 자료의 80%에서 선정한 1개·5개 특징의 점수를 고정하여 사용한다. 특징 개수는 1, 2, 4, 5, 8개이며 이미지 기준과 텍스트 기준을 모두 계산한다. 새로운 캡션 변형에서는 우선 기존 AUROC 선정 기준을 사용한다. 네 선정 기준 전체를 다시 비교하는 작업은 이 실행에 포함하지 않는다.

후속 분석의 특징 선정과 분류기 학습에는 학습 이미지의 80%를 사용하고 나머지 20%로 설정을 고른다. 최종 평가는 기존 검증 이미지에서 수행한다. 전체 학습 자료에서 대표 특징을 고르는 초기 RQ1 분석은 탐색적 기술 통계로 구분한다. SAE 학습에는 기존 실험과 마찬가지로 학습 이미지 전체에 대응하는 텍스트를 사용한다.

이미지 임베딩과 가림 결과는 입력 해시 및 이미지 SAE 가중치가 같은 경우에만 재사용한다. 새 학습 캡션의 임베딩과 텍스트 특징 활성값은 다시 계산한다. 검증 캡션 임베딩은 같으면 재사용할 수 있지만, 텍스트 SAE가 달라졌으므로 검증 텍스트 특징 활성값은 다시 계산한다.

서버에서 다음 명령으로 실행한다.

```bash
cd /mnt/working/mm-sae
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 TOKENIZERS_PARALLELISM=false \
  .venv/bin/python scripts/run_experiment_sequence.py --config configs/sharegpt4v-sequence.yaml
```

전체 실행 상태는 `/mnt/working/mm-sae/runs/sharegpt4v-sequence-2026-09-29/scheduler.json`에 기록한다. 세부 진행률과 현재 작업의 측정 속도에 따른 예상 잔여 시간은 각 결과 폴더의 `progress.json`에 10초마다 기록한다. 아직 측정하지 않은 후속 단계의 완료 시각을 확정해서 표시하지 않는다.

```bash
cd /mnt/working/mm-sae
.venv/bin/python -m mm_sae.cli status --run-dir runs/sharegpt4v-2026-09-29
.venv/bin/python -m mm_sae.cli status --run-dir runs/sharegpt4v-feature-sets-2026-09-29
```

학습·가림 결과는 `/mnt/working/mm-sae/runs/sharegpt4v-2026-09-29`에 저장한다. 후속 RQ1·RQ2 결과와 그림은 `/mnt/working/mm-sae/runs/sharegpt4v-feature-sets-2026-09-29`에 저장한다. 오류가 발생하면 다음 단계로 넘어가지 않고 로그에 남긴다. 동일한 코드·설정으로 재실행하면 완료된 단계와 학습 체크포인트를 재사용한다.
