# 여러 특징을 사용하는 RQ2와 RQ1의 실행 전 계획

**특징 여러 개를 사용해 원본·가림 AUROC를 높일 수 있는지, 그 개선이 실제 범주 구별과 모달리티 간 대응에도 이어지는지 함께 검증한다.** 원래 문서의 RQ2, 최근 결과를 반영한 RQ2 수정안, 여러 특징을 사용하는 RQ1을 세 실험 묶음으로 실행한다. AUROC가 높아지는 결과를 미리 전제하지 않는다.

사용자가 이 계획을 승인했다. 설정은 `/Users/jihoonkwon/Desktop/projects/research/MM-SAE/mm-sae/configs/feature-sets-review.yaml`에 있다. 공통 모듈과 실행기를 구현했으며, 소규모 검사 뒤 같은 과학적 설정으로 서버에서 실행한다. 아래의 방법과 범주 선택 기준을 결과에 맞추어 바꾸지 않는다.

**여러 특징의 AUROC는 활성값을 결합한 뒤 계산한다.** 개별 특징의 AUROC를 평균내지 않는다. 범주 c에 대해 학습용 원본·가림 AUROC가 높은 순서로 특징을 고르고, 특징 수 n을 1, 2, 4, 5, 8로 바꾼다. 1, 2, 4, 8은 원래 계획의 비교이며 5는 최근 논의와 연결하는 조건이다. n은 범주를 읽는 데 사용하는 좌표 수이며, 기존 SAE가 입력마다 최대 8개 특징을 활성화하는 설정과는 별개다.

이미지와 텍스트에서 각각 다음 점수를 만든다.

`범주 점수 = 절편 + Σ(가중치 × 표준화한 특징 활성값)`

이미지에서는 범주 c가 있는 원본 이미지에 정답 1, 같은 이미지에서 c를 흰색으로 가린 이미지에 정답 0을 부여한다. 텍스트에서는 c를 언급한 원본 캡션에 정답 1, 사전에서 찾은 해당 표현을 UNK 토큰으로 가린 캡션에 정답 0을 부여한다. 현재 사전과 가림 규칙을 유지한다. 이미지 조건에 맞춘다고 언급이 없는 캡션을 텍스트 양성 표본에 넣지 않는다.

이 정답을 구별하도록 작은 선형 분류기의 가중치를 학습한다. 각 특징은 제거 전 활성값이 큰 방향으로 골랐으므로, 이 가림 점수에서는 가중치를 0 이상으로 제한한다. 실제로 0이 아닌 가중치 수도 기록한다. n이 1이면 원래 특징 활성값을 그대로 사용해 원래 AUROC와 Pearson 상관계수를 보존한다. n이 2 이상이면 선택한 n개를 입력으로 사용하되 실제 사용한 좌표 수는 n 이하일 수 있다.

평가 자료에서 원본 점수와 가림 점수의 AUROC를 계산한다. RQ1의 상관계수에는 분류 확률로 변환하기 전의 선형 점수를 사용한다. 확률 변환 때문에 상관계수가 달라지는 효과를 섞지 않기 위해서다. 가중치 학습 없이 표준화한 활성값을 같은 비중으로 더하는 조건도 함께 계산한다. 이 비교는 여러 좌표를 추가한 효과와 가중치를 맞춘 효과를 구분한다.

이 가림 점수와 별도로, 원본 이미지의 범주 존재 여부와 원본 문장의 범주 언급 여부를 예측하는 일반 선형 분류기도 사용한다. 이 분류기의 계수는 양수와 음수를 모두 허용한다. 학습 목적이 다른 두 점수를 같은 AUROC로 합치지 않는다.

**세 실험에서 데이터 분할과 특징 후보를 공유한다.**

- 기존 이미지·텍스트 SAE와 임베딩 모델을 고정한다. 이미 저장한 원본·가림 활성값을 재사용한다. 새로운 SAE 학습이나 대규모 이미지 추론은 하지 않는다. 새로 학습하는 것은 작은 선형 분류기와 회귀 예측기의 계수다.
- COCO train의 이미지 ID를 난수 시드 0으로 나누어 80%를 특징 선택·계수 학습에, 20%를 규제 강도와 비교용 단일 특징 선택에 사용한다. 한 이미지의 모든 캡션과 가림 변형을 같은 집단에 둔다. COCO val은 고정된 모델의 평가에 사용한다. 이미 관찰한 자료이므로 최종 미공개 시험 자료라고 주장하지 않는다.
- 특징별 AUROC를 train의 80%에서 다시 계산한다. 전체 train으로 고른 특징을 새 분할의 후보인 것처럼 재사용하지 않는다. 원본 활성값의 평균과 표준편차도 학습용 자료에서만 계산해 모든 평가에 고정한다.
- 규제 강도 후보는 0.0001, 0.001, 0.01, 0.1, 1, 10, 100이다. 분류는 조정용 자료의 평균 로그 손실, 회귀는 평균 제곱오차로 고른다. 동률이면 더 강한 규제를 선택한다. 평가 자료로 특징 수나 규제 강도를 고르지 않는다. 모든 n의 결과를 보고한다.
- 단일 특징 AUROC가 낮다는 이유로 범주를 제외하지 않는다. 비교할 범주와 예측할 목표 좌표를 n 사이에서 고정한다. 표본 부족, 상수 점수, 빈 집단 때문에 계산할 수 없는 경우는 사유와 개수를 보고하며 0점으로 넣지 않는다.
- 주 결과는 물체·배경을 모두 포함하고, 물체와 배경의 결과도 별도로 보고한다. AUROC별 비교 집단은 n=1의 조정용 AUROC로 고정한다. n을 늘릴 때마다 높은 점수의 범주만 새로 뽑아 개선으로 보고하지 않는다.
- 분류 AUROC와 회귀 예측오차의 불확실성은 평가 이미지 ID를 1,000회 재추출해 계산한다. 같은 이미지의 캡션과 가림 변형은 함께 재추출한다. 이 구간은 고정된 SAE·특징 선택·분할에 조건부인 평가 불확실성이며 SAE 재학습의 변동은 포함하지 않는다.

**첫 번째 묶음은 원래 RQ2의 두 실험을 수행한다.** 원래 계획은 `/Users/jihoonkwon/Desktop/projects/project-pages/f4750a4b/multimodal-SAE/2026-08-31.html`에 있다. 구체적 분류기와 목표 집합처럼 원래 문서가 지정하지 않은 사항은 아래와 같이 고정한다.

| 원래 RQ2의 실험 | 실행 방법 | 결과로 판단할 내용 |
|---|---|---|
| 개념을 예측하는 데 필요한 특징 수를 비교한다. | 범주별 가림 AUROC 상위 n개 활성값에 선형 분류기를 학습한다. 원본 이미지에서는 범주 존재 여부, 원본 캡션에서는 사전으로 검출한 언급 여부를 예측한다. | n에 따른 평가 AUROC 곡선을 이미지·텍스트에서 비교한다. 여러 특징이 범주 정보를 더 잘 읽는 데 도움이 되는지 확인한다. |
| 상대 모달리티의 원본 활성값을 설명하는 데 필요한 특징 수를 비교한다. | 범주별 상대 모달리티의 상위 n개 특징으로 목표 모달리티의 상위 8개 특징 활성값을 예측한다. 예측 목표 8개는 모든 n에서 고정한다. 원본 이미지·캡션 쌍 전체에서 두 방향을 평가한다. | 평가 R²와 목표 특징의 디코더 방향을 반영한 복원 오차를 비교한다. 특징 하나보다 여러 특징이 상대 활성값을 더 잘 설명하는지 확인한다. |

R²는 평균만 예측하는 기준과 비교해 제곱오차를 얼마나 줄였는지 나타낸다. 복원 오차는 예측한 목표 활성값과 실제 목표 활성값의 차이에 해당 SAE의 디코더 방향을 곱한 뒤 계산한다. 전체 임베딩 재구성 성능이라고 부르지 않는다. 범주별 고정한 목표 특징들이 만드는 기여분의 오차다.

무작위 특징 집합과 함께 자주 등장하는 다른 범주의 특징 집합을 대조 조건으로 둔다. 다른 범주는 학습용 이미지 주석에서 양의 동시 등장 상관이 가장 높은 범주로 고정한다. 실제 특징 번호가 겹치면 겹친 사실을 기록하고 유리한 다른 범주로 바꾸지 않는다. 적합한 다른 범주가 없으면 해당 대조 조건을 계산 불가로 남긴다.

무작위 특징은 학습용 원본 활성 빈도가 가까운 후보 20개에서 고르며, 난수 시드 11부터 15까지 5회 반복한다. 선택할 때 중복 좌표를 허용하지 않는다. 개념 예측에는 기존 1위 특징에 무작위 n−1개를 더하는 조건도 둔다.

원래 개념 예측 곡선과 함께, 모든 활성 특징 중 개념 예측에 가장 적합한 단일 특징을 조정용 자료에서 고른 결과도 별도 기준으로 둔다. 가림 AUROC로 고른 대표가 부적절해서 여러 특징이 좋아 보이는 경우를 확인하기 위해서다. 이 단일 특징의 계수는 학습용 자료에서 맞추고 선택만 조정용 자료에서 한다.

두 모달리티에서 같은 n의 성능이 좋다고 특징 간 1대1 대응을 입증한 것으로 해석하지 않는다. 또한 추가 특징의 개선이 통계적으로 불분명하다는 사실만으로 성능이 포화되었다고 단정하지 않는다. 곡선과 성능 차이의 불확실성을 보고한다.

**두 번째 묶음은 단일 대표 선택의 문제와 연결 구조의 문제를 분리한다.**

| 수정 RQ2의 실험 | 실행 방법 | 필요한 비교 |
|---|---|---|
| 같은 1위 특징을 공유하는 서로 다른 범주를 직접 구별한다. | 학습용 자료에서 1위 특징을 공유하는 모든 범주 쌍을 고정한다. A만 있는 원본과 B만 있는 원본을 분류한다. 텍스트는 A만 언급하거나 B만 언급한 문장을 사용한다. 각 범주의 상위 n개 합집합을 입력으로 쓰며 중복 좌표를 제거한다. | 공유된 특징 하나, 합집합에서 고른 가장 좋은 단일 특징, 전체 활성 특징에서 고른 가장 좋은 단일 특징, 합집합 전체를 비교한다. 합집합은 최대 2n개이므로 실제 좌표 수를 표기한다. |
| 모달리티 사이의 1대1 연결 제약이 가림 반응 예측을 제한하는지 확인한다. | 이미지에 범주 c가 있고 캡션에도 c가 언급된 쌍에서, 이미지와 텍스트 각각의 원본 활성값에서 가림 활성값을 뺀 변화를 구한다. 한쪽 변화로 다른 쪽 변화를 두 방향으로 예측한다. | 양쪽 모두 독점적인 1대1 연결, 목표마다 입력 하나를 쓰되 재사용 허용, 목표마다 입력 최대 n개와 재사용 허용을 비교한다. |

직접 구별에서는 처음부터 같은 번호라는 이유로 단일 특징의 AUROC를 0.5로 놓지 않는다. 활성값 크기만으로 두 범주를 구별할 수 있기 때문이다. 후보 집합이 다른 조건끼리 비교한 결과도 구분한다. 여러 특징이 기존 대표보다 좋지만 최선의 단일 특징과 비슷하다면, 대표 선택의 문제로 해석한다.

가림 반응 예측에서는 모든 범주의 상위 8개 합집합을 모달리티별 후보로 사용한다. 같은 좌표는 한 번만 남긴다. 여러 범주에 걸쳐 하나의 공통 연결을 학습하고, 같은 좌표를 범주마다 복제해 1대1 제약을 피하지 않는다. 모든 조건에서 입력 후보 집합, 목표 좌표 집합과 평가 표본을 고정한다. 범주별 총 학습 비중을 같게 하고, 각 범주 안에서는 이미지별 총 비중을 같게 나눈다. 한 이미지에 해당 범주를 언급한 캡션이 여러 개 있으면 그 이미지의 비중을 캡션 수로 나눈다.

모든 단일 입력·목표 조합에 대해 계수와 절편을 학습하고 조정용 예측오차를 구한다. 1대1 조건은 이 오차를 최소화하는 헝가리안 연결을 사용하고, 입력 재사용 조건은 목표마다 가장 좋은 입력을 선택한다. 원본 Pearson 상관으로 고른 부적절한 짝 때문에 1대1 조건이 불리해지는 것을 줄이려는 비교다.

여러 입력 조건은 이미 고른 입력들로 설명하지 못한 학습용 변화의 오차를 가장 많이 줄이는 입력을 하나씩 추가한다. 규제 강도별로 이 과정을 수행한 뒤 조정용 오차로 선택한다. 전체 조합의 최적해를 찾았다고 주장하지 않는다. 1개 입력의 최선 선택보다 여러 입력이 평가 자료에서 개선되는지를 확인한다.

연결되지 않았거나 연결해도 조정용 오차가 개선되지 않는 목표는 학습용 평균을 예측한다. 모든 고정 목표를 포함한 결과와 공통으로 연결된 목표만의 결과를 함께 보여준다. 연결된 쉬운 목표만 남겨 평균 성능이 좋아지는 문제를 방지한다. 평가 자료에서 목표 변화가 상수면 R² 대신 예측오차와 해당 목표 수를 보고한다.

같은 범주 안에서 이미지 쪽 대응을 이미지 ID 단위로 섞은 조건도 실행한다. 한 이미지의 모든 캡션을 함께 옮긴다. 범주별 평균 반응만으로 얻은 이득과 실제로 같은 이미지·캡션의 반응을 예측한 이득을 구분한다. 무작위 특징 후보 조건도 사용한다. 가림 면적이나 편집 흔적의 영향을 완전히 제거한 인과적 의미 대응이라고 주장하지 않는다.

**세 번째 묶음은 여러 특징을 합친 점수로 현재 RQ1의 세 질문을 다시 평가한다.** 범주 점수의 가중치는 이미지와 텍스트에서 각각 원본·가림 구별로만 학습하며, 두 모달리티의 상관이나 올바른 짝 점수를 높이도록 학습하지 않는다.

원본 이미지·캡션 쌍 전체에서 이미지 범주 c의 점수와 텍스트 범주 d의 점수 사이 Pearson 상관을 계산한다. 이미지 기준은 이미지 c와 텍스트의 나머지 170개 범주를 비교하고, 텍스트 기준은 텍스트 c와 이미지의 나머지 170개 범주를 비교한다. 대각 원소는 양쪽의 범주 이름이 같은 경우다.

| 현재 RQ1의 질문 | n개 특징으로 다시 계산할 값 |
|---|---|
| 서로 다른 범주가 함께 등장할수록 점수가 높아지는가? | 이미지 주석 상관의 0.2 구간별로 범주 점수 간 상관계수의 평균, 표준편차, 최솟값, 1·2·3사분위수, 최댓값을 집계한다. 0 이상 구간을 주 그림에, 음수 구간을 보조 결과에 둔다. |
| 다른 범주의 점수가 같은 범주의 점수를 넘는가? | 각 기준 범주에서 다른 170개 중 하나라도 대각 점수를 넘는 비율과 전체 방향별 범주 쌍 중 대각을 넘는 비율을 계산한다. 두 방향과 네 가지 물체·배경 조합을 모두 보고한다. 정확한 동점은 초과에 넣지 않고 별도로 센다. |
| 양의 동시 등장 관계를 제거하면 점수가 낮아지는가? | 원래 범주별 등장 비율은 유지하고, 양의 주석 상관만 범주 쌍별 가중치 조절로 0으로 만든다. 같은 고정 범주 점수로 상관계수를 다시 계산해 원본과 비교한다. 점수의 가중치를 다시 학습하지 않는다. |

세 번째 질문에서 사용하는 네 집단은 A·B 모두 없음, B만 있음, A만 있음, 둘 다 있음이다. 필요한 집단에 관측이 없으면 결과를 계산 불가로 표시한다. 존재하지 않는 이미지를 만들거나 음의 상관까지 0으로 바꾸지 않는다. 집단별 이미지 수, 가중치의 최댓값과 유효 표본 수도 저장해 적은 이미지에 지나치게 의존한 결과를 확인한다. 각 쌍의 통제는 별도 분포에서 수행하므로 모든 쌍을 동시에 독립으로 만든 하나의 자료나 하나의 전역 상관행렬로 해석하지 않는다. 주된 개선 지표는 점수 감소이며, 통제 후 순위 비율은 보조 결과로 둔다.

여러 특징을 결합한 원본·가림 AUROC의 분포와 0.6, 0.7, 0.8 이상 범주 수도 이미지·텍스트, 물체·배경별로 보고한다. 같은 결합 점수를 그대로 사용해 원본 자료에서 범주 존재·언급 여부를 구별하는 AUROC도 계산한다. 가림 구별 점수만 좋아졌는지, 같은 점수가 원본의 개념 구별에도 도움이 되는지 확인하기 위해서다. 이 점수에는 범주 검출용 분류기를 다시 맞추지 않는다.

새 주 결과는 평가용 val에서 n=1과 n>1을 같은 범주·표본으로 비교한다. 원래 RQ1의 상관은 train에서 계산했으므로 기존 수치와 새 수치의 차이를 n의 효과로 직접 비교하지 않는다. 별도 재현 단계에서 기존 대표와 train 자료로 원래 29,070개 방향별 비교를 복원하고, 그 결과가 저장된 값과 일치하는지 확인한다.

여기서 n>1의 상관계수는 원래 개별 SAE 특징 사이의 상관계수가 아니라, 범주 정보를 읽도록 학습한 특징 결합 점수 사이의 상관계수다. 결과가 좋아져도 모든 개별 특징의 의미 대응을 해결했다거나 비지도 대응 방법을 얻었다고 주장하지 않는다.

**결과 그림은 우선 8개를 저장한다.** 각 그림에서 두 모달리티 또는 두 예측 방향을 나란히 배치한다. 주 그림은 n=1과 n=5의 비교를 중심으로 만들되 특징 수에 따른 곡선에서는 모든 n을 표시한다. 나머지 상세 분포와 범주별 값은 보조 그림과 CSV에 저장한다.

원래 계획의 여러 좌표에 선형 분류기를 학습하는 방식은 [SAEBench의 sparse probing](https://arxiv.org/html/2503.09532v3#S3.SS2.SSS3)과 같은 평가 접근을 따른다. 이 연구는 특징 1개·2개·5개의 조합을 평가했다. 이 선행 연구가 현재 멀티모달 대응의 개선을 보장하지는 않는다.
