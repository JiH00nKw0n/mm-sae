# 주석으로 따로 고른 대표 좌표가 모달리티 사이에서 일치하는지 확인한다

이 실험은 범주 정답으로 이미지와 텍스트의 대표 좌표를 각각 고른 뒤, 기존 대응 방법이 두 좌표를 같은 번호와 같은 점수 방향으로 연결했는지 평가한다. 검색 성능이나 AUROC 자체를 대응 정확도라고 부르지 않는다. 기존 SAE와 대응 계수를 고정하므로 새로운 모델 학습은 하지 않는다.

## 여러 activation을 조합한 좌표에서도 대표를 하나 고른다

헝가리안 대응의 좌표는 이미지 특징 하나와 텍스트 특징 하나로 구성된다. CCA의 좌표는 여러 이미지 activation의 가중합과 여러 텍스트 activation의 가중합으로 구성된다. Sparse CCA도 가중합을 사용하지만 각 좌표에 포함할 수 있는 activation 수를 제한한다.

주석 기반 평가는 이러한 최종 좌표 중에서 범주마다 대표를 하나 고른다. 예를 들어 이미지 주석으로 스키를 가장 잘 구별하는 좌표가 12번이고, 텍스트 주석으로 따로 고른 좌표도 12번이며 점수 방향도 같으면 일치로 센다. 이미지에서는 12번, 텍스트에서는 38번을 고르면 일치하지 않는다. CCA 평가에서 대표 좌표 하나를 고른다는 것은 SAE activation 하나만 사용한다는 뜻이 아니다.

## 대응을 학습한 자료와 대표 좌표를 고르는 자료를 분리한다

주 분석에는 기존 대응 학습에서 제외한 COCO train2017 이미지 23,657장과 해당 캡션을 사용한다. SAE 자체는 COCO train2017로 학습했으므로 주 분석 자료가 SAE 학습에서도 제외된 것은 아니다. 이미지 ID를 기준으로 자료를 두 부분으로 나눈다. 서로 다른 부분의 이미지와 텍스트 주석을 사용해 대표 좌표를 고른다. 같은 이미지의 캡션은 모두 같은 부분에 속한다. 따라서 하나의 이미지와 그 이미지의 캡션을 양쪽 대표 선정에 동시에 사용하지 않는다.

COCO val2017 이미지 5,000장과 해당 캡션에서도 같은 절차를 별도로 수행한다. 이 자료는 앞선 분석에서 이미 살펴보았으므로 미관측 최종 시험이라고 부르지 않는다. 분석마다 표본 수와 사용 가능한 범주 수를 함께 기록한다.

이미지 정답은 모델에 들어간 중앙 자르기 영역의 COCO 객체 존재 여부다. 이번 대표 일치 실험에서는 그 이미지의 객체 정답을 해당 캡션에도 부여한다. 따라서 텍스트 평가는 캡션에 단어가 직접 등장하는지를 판단하는 실험이 아니라, 해당 캡션의 짝 이미지에 어떤 객체가 있는지를 구별하는 실험이다. 원본 이미지와 가림본을 비교하는 AUROC도 아니다.

## 모든 방법에 같은 물체 범주와 같은 유효성 기준을 적용한다

COCO 물체 80개를 평가 후보로 둔다. 주 비교에 사용한 이미지 A 부분에서 양성 이미지가 50개 이상이고 텍스트 B 부분에서 양성 캡션이 50개 이상이며, 각 부분에 음성도 존재하는 범주만 공통 평가에 사용한다. 양성 캡션 수는 그 캡션의 짝 이미지에 해당 객체가 있는지를 기준으로 센다. 결과 표에는 일치한 범주 수와 실제 평가한 범주 수를 함께 적는다. 방법별로 유리한 범주만 따로 고르지 않는다.

양쪽 모달리티에서 상수가 아닌 최종 좌표만 후보로 사용한다. 원래 activation이 특정 비율 이상 켜졌는지를 기준으로 하는 필터는 사용하지 않는다. CCA의 가중합 좌표에는 원래 SAE activation과 같은 희소 활성 기준을 적용하기 어렵기 때문이다. 헝가리안과 CCA의 후보 좌표 수는 결과에 명시한다. 헝가리안의 원래 연결 수인 437개에 맞춰 CCA도 437개 좌표를 사용하는 조건을 별도로 비교한다. 상수 좌표를 제외하면 실제 유효 후보 수는 정확히 같지 않다.

## 주석으로 좌표와 점수 방향을 정한다

범주가 있는 표본과 없는 표본을 각 좌표의 점수가 얼마나 잘 구별하는지 AUROC로 계산한다. 점수가 낮을 때 범주가 있다는 정보를 나타내는 좌표도 고려하기 위해 양의 방향과 음의 방향을 모두 비교한다. AUROC가 큰 좌표와 점수 방향을 대표로 정한다. 동점은 좌표 번호 등 코드에 명시한 결정적 규칙으로 처리한다.

최종 Top-1 지표는 양쪽에서 독립적으로 고른 대표의 좌표 번호와 점수 방향이 모두 같은 범주의 비율이다. Top-5와 Top-10은 한쪽에서 고른 대표가 상대 모달리티의 주석 기반 상위 5개 또는 10개 후보 안에 같은 방향으로 포함되는지를 센다. 이 두 지표는 이미지나 캡션을 검색하는 Recall@5·10이 아니다.

모든 방법에서 양의 방향만 허용하고 원래 AUROC로 대표를 고르는 조건도 별도로 계산한다. 이 조건은 부호를 뒤집지 않는 대표 선정과 주 분석의 차이를 확인하기 위한 비교다.

## 우연 일치와 대표 선정의 불안정성을 함께 확인한다

무작위 연결 조건은 대표 선정 결과를 유지하고 모달리티 사이 연결을 섞는다. 범주 섞기 조건은 서로 다른 범주의 대표끼리 비교해 범주와 무관하게 같은 좌표가 반복 선정되는 영향을 확인한다. 동일 모달리티의 독립 자료에서 대표를 다시 고른 조건은 이미지끼리 또는 텍스트끼리도 대표가 얼마나 안정적으로 유지되는지 확인한다.

여러 범주가 같은 좌표를 대표로 고른 횟수도 함께 기록한다. 높은 일치율이 좌표 하나가 개념 하나만 표현한다는 뜻은 아니다. 두 모달리티에서 눈과 스키를 같은 좌표가 모두 예측하면 두 범주의 일치가 높더라도 눈과 스키를 따로 표현했다고 해석할 수 없다.

## 이번 실험이 답하는 범위를 한정한다

이번 실험은 COCO로 학습한 기존 SAE와 대응 방법을 비교한다. CC3M으로 학습한 이전 논문의 결과를 그대로 재현한 실험은 아니다. 물체 주석과 대표 좌표의 일치를 비교하므로 모든 의미 개념에 대한 정확도를 추정하지 않는다. 또한 텍스트에는 이미지의 객체 정답을 부여했으므로 캡션 생략의 영향이 포함된다.

대표 하나의 일치는 엄격한 기준이다. 같은 개념을 나타내는 좌표가 여러 개라면 양쪽에서 서로 다른 번호를 골라도 각각 개념을 잘 구별할 수 있다. 반대로 양쪽에서 같은 번호를 골라도 해당 좌표가 여러 동시 등장 개념을 공유할 수 있다. 따라서 Top-1, Top-5·10, 동일 모달리티의 대표 선정 안정성, 대표 공유 사례를 함께 해석한다.
