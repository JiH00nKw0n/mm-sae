# 검색 성능과 개념 구별 성능을 함께 비교한다

이번 실험은 기존 대응 방법의 검색 성능과 개념 구별 성능을 함께 측정한다. 연결이 적다는 사실만으로 해석 가능하다고 판단하지 않는다. 대응 방법이 실제로 만든 좌표를 고정하고, 양쪽에서 같은 개념을 구별하는지 확인한다.

## 세 실험이 서로 다른 질문에 답한다

1. 기존 헝가리안, CCA, Procrustes, Sinkhorn에서 검색 성능과 개념 구별 성능이 함께 유지되는지 확인한다. 전체 계수와 연결을 제한한 조건을 비교한다.
2. 동일한 연결을 허용한 회귀에서 음수 계수를 허용하는 조건과 양수만 허용하는 조건을 비교한다. 두 방향의 회귀를 각각 학습하며 정규화 강도는 모두 0.01로 고정한다. 다시 학습한 회귀는 Procrustes라고 부르지 않는다.
3. CCA를 학습한 뒤 계수를 제거하는 방법과 처음부터 좌표마다 사용 가능한 특징 수를 제한한 Sparse CCA를 비교한다. 좌표 크기의 영향을 구분하기 위해 계수를 제거한 뒤 학습 공분산으로 다시 정규화하는 조건도 포함한다.

## 자료와 분할을 고정한다

SAE와 활성값은 `/Users/jihoonkwon/Desktop/projects/research/MM-SAE/mm-sae/runs/elice-rq1-lexicon2`에 저장된 기존 COCO 모델을 사용한다. 두 SAE에는 각각 4,096개 특징이 있고 입력마다 상위 8개 특징을 활성화한다. 대응 학습에서는 학습 자료에서 값이 변하는 이미지 특징 906개와 텍스트 특징 437개를 사용한다. 대응 행렬의 행·열 위치와 원래 SAE 특징 번호를 별도로 보존한다.

대응 학습은 COCO 학습 이미지 94,630장으로 수행한다. 개념별 좌표와 점수의 방향은 이 이미지들과 겹치지 않는 학습 이미지 23,657장에서 정한다. 평가는 COCO 검증 이미지 5,000장과 캡션 25,014개에서 수행한다. 같은 이미지의 모든 캡션은 같은 분할에 속한다. 검증 자료는 이전 분석에서 이미 관찰했으므로 이번 결과도 탐색 결과로 해석한다.

이미지 정답은 모델의 중앙 자르기 영역에 해당 범주가 존재하는지 나타내는 COCO-Stuff 주석이다. 텍스트 정답은 수정된 사전으로 판정한 캡션 내 언급 여부다. 텍스트 정답을 사람이 검수한 의미 정답이라고 부르지 않는다. 물체 80개와 배경 91개를 모두 남기며, 양성 또는 음성 표본이 없는 범주는 평가 불가로 기록한다. 방법에 따라 유리한 범주를 제외하지 않는다.

## 의미 평가는 원래 대응 점수를 그대로 사용한다

각 방법은 이미지 점수와 텍스트 점수를 동일한 좌표 순서로 제공한다. 헝가리안은 원래 특징과 연결된 상대 특징을 사용한다. Sinkhorn은 가중치 합으로 나눈 상대 특징의 가중평균을 사용한다. Procrustes와 회귀는 부호를 유지한 상대 특징의 가중합을 사용한다. CCA는 양쪽에서 공통 좌표를 만드는 가중합을 사용한다.

이미지에서 텍스트로 개념을 전달하는 평가에서는 조정 자료의 이미지 정답만으로 좌표 하나와 점수 방향을 정한다. 개념 있음·없음 AUROC가 가장 높은 좌표와 방향을 선택한다. 텍스트 정답은 이 선택에 사용하지 않는다. 선택한 좌표와 방향을 고정하고 검증 이미지와 검증 캡션에서 각각 AUROC를 계산한다. 텍스트에서 이미지로 전달하는 평가는 반대로 수행한다. 동점은 작은 좌표 번호를 우선하며, AUROC가 정확히 0.5일 때는 양의 방향을 사용한다.

AUROC는 개념이 있는 표본의 점수가 없는 표본보다 클 확률이며 동점에는 절반을 부여한다. 원본·가림 AUROC가 아니다. 선택 단계와 평가 단계에서 별도의 다변수 분류기를 학습하지 않는다. 이미지 AUROC와 텍스트 AUROC를 각각 보고하고, 두 값 중 작은 값도 함께 기록한다. 작은 값은 한쪽 성능만 높은 경우를 드러내는 보조 요약이며 새로운 정확도 지표라고 부르지 않는다.

높은 AUROC는 주석 개념을 잘 구별한다는 뜻이다. 동시 등장하는 다른 개념과 구별되거나 좌표가 하나의 개념만 표현한다는 뜻은 아니다. 눈과 스키처럼 같은 좌표가 여러 개념의 대표로 선택되는 사례도 별도로 확인한다.

## Sparse CCA의 계산 범위를 명시한다

원래 SAE 좌표에서 이미지와 텍스트 계수를 각각 최대 4개, 8개, 16개 사용하도록 제한한다. 공통 좌표 수는 256개이고 양쪽 공분산에는 기존 CCA와 같은 0.01 정규화를 적용한다. 선택된 특징 안에서 계수를 계산하고, 특징을 교체하며 목적값을 높이는 지역 탐색을 수행한다. 다음 좌표는 앞서 설명한 공분산 성분을 제거한 행렬에서 구한다.

이 절차가 전체 가능한 특징 조합 중 최적해를 찾는다고 보장하지 않는다. 희소 좌표들은 서로 상관될 수 있다. 마지막에는 원래 학습 자료에서 양쪽 공통 좌표의 공분산이 양수가 되도록 텍스트 쪽 부호를 정한다. 이 방향 선택에 검증 자료나 개념 정답을 사용하지 않는다. 부호 변경 전 계수와 반복별 목적값도 저장한다.

이번 비교는 이러한 희소 학습 절차와 계수 제거의 차이를 평가한다. 계수 값, 사용한 특징, 순차적 성분 추출이 함께 달라지므로 성능 차이를 희소성 하나의 효과라고 해석하지 않는다.

## 실행과 결과를 확인한다

작업 위치는 `/Users/jihoonkwon/Desktop/projects/research/MM-SAE/mm-sae`다. 대응 계수만 다시 학습하며 새 이미지 추론이나 SAE 학습을 실행하지 않는다.

```bash
.venv/bin/python -m experiments.mapping_semantics.fit_sign --support-grid 8 16 --penalty 0.01

```
