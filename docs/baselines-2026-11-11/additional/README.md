# 전체 좌표와 축당 최대 32개 특징으로 평가한 11개 방법

이미지·텍스트 SAE와 대응 행렬을 고정하고, 개념 예측에는 축당 최대 32개 원래 특징을 썼다. 검색에는 각 방법의 전체 출력 벡터를 썼다. 헝가리안·Sinkhorn·Procrustes는 각각 4,096개 좌표, 공유 SAE 두 방법은 각각 8,192개 좌표, 나머지는 256개 축으로 평가했다. 희소 PLS-SVD와 희소 CCA는 학습된 계수가 축당 최대 16개다. [예측 손실·정밀도·재현율·F1과 2차원 그림](../README.md)

네 검색 자료 평균 R@5는 PLS-SVD가 이미지 질의 56.05%, 캡션 질의 54.36%로 가장 높았다. CCA에 공분산 회전을 적용하면 COCO 물체에서 혼합도는 0.558에서 0.649로 높아졌고 분산도는 0.723에서 0.686으로 낮아졌다. 같은 회전에서 synCOCO의 제거 물체 반응은 평균 16.14%p 감소에서 21.88%p 감소로 커졌고, 유지 물체의 평균 절대 변화도 4.87%p에서 7.27%p로 커졌다.

## 네 벤치마크에서 정답 이미지와 캡션 검색

각 칸은 **R@1 / R@5 / R@10 (%)**이다. 이미지 질의에서는 상위 후보에 정답 캡션이 하나라도 있으면 성공이고, 캡션 질의에서는 원래 이미지가 순위 안에 들면 성공이다. 각 방향과 순위에서 네 데이터셋의 비율을 같은 비중으로 평균했다. 모든 방법은 CLIP의 같은 77토큰 입력 한도를 사용했다. 이 한도를 넘은 캡션은 DOCCI 94.4%, IIW 99.0%였다. [정밀값과 재사용 내역](retrieval.csv)

## 한 축의 개념 혼합도와 한 개념의 축 간 분산도

각 칸은 **혼합도 / 분산도**이며 둘 다 낮을수록 예측 기여가 집중된다. 각 축과 개념 조합에서 출현율만 예측할 때보다 검증 교차엔트로피가 줄어든 양을 기여로 사용하고, 음의 차이는 0으로 두었다. 혼합도는 한 축의 기여가 여러 개념에 얼마나 퍼지는지 계산한 정규화 엔트로피를 축의 총 기여로 가중 평균한 값이다. 분산도는 한 개념의 기여가 여러 축에 얼마나 퍼지는지 계산한 정규화 엔트로피를 총 기여가 양수인 개념에 대해 평균한 값이다. 엔트로피는 각각 개념 수와 평가 축 수의 로그로 나눈다. 학습 표본에서 항상 0인 축은 출현율 예측기와 같으므로 기여를 정확히 0으로 두었다. 후보 축 수는 방법마다 다르며, 두 지표는 개념의 검출 성능과 함께 읽어야 한다. ## 같은 이미지에서 개념을 편집하기 전과 후의 반응

synCOCO는 원본과 물체를 제거한 이미지 2,504쌍, synCUB는 원본과 새의 속성을 바꾼 이미지 2,933쌍을 사용했다. synCOCO에는 원본 COCO에서, synCUB에는 원본 CUB에서 학습하고 검증 손실로 선택한 개념별 축과 분류기를 고정했다. 각 원본·편집본에 동일한 분류기를 적용하고 개념 존재의 **예측 확률 변화(%p)**를 계산했다. 제거한 개념은 음수, 추가한 개념은 양수일 때 기대한 방향이다. 유지한 개념은 쌍마다 절댓값을 취한 뒤 평균하므로 0에 가까울수록 안정적이다. 평균 단위는 이미지 쌍과 개념의 조합이다. ### 같은 조건의 측정값을 재사용한 범위

검색 44개 조합 중 COCO 11개 방법과 다른 세 자료의 PLS-SVD·CCA 6개 조합은 대응 가중치와 후보 ID가 같은 기존 측정값을 재사용했다. 나머지 27개 조합을 새로 평가했다. 각 자료에서 모든 방법의 이미지·캡션 순서가 일치하는지 확인하고, 저장한 질의별 정답 순위로 표에 실린 여섯 검색 점수를 다시 계산했다.

혼합도와 분산도는 희소 PLS-SVD·희소 CCA 및 공유 SAE 두 방법에서 기존 전체 축별 검증 손실을 재사용했다. [이전 측정 설정](../../baselines-2026-11-08/README.md) 나머지는 최신 조건에서 모든 축의 손실을 계산했다. COCO·COCO-Stuff 원본 및 이미지 편집 쌍에서 헝가리안·Procrustes·Sinkhorn의 이미지 축은 동일하다. 또한 CCA 공분산 회전과 회전 후 상위 64개를 남긴 조건은 상위 32개 계수가 이미지·텍스트 모두 같아 개념 평가값을 공유한다. [전체 평가 설정](../../../configs/complete_val2017_top32.yaml)

[검증 기록](verification.json)에는 후보 ID, 질의별 순위, 편집 쌍·개념 기록의 해시와 전체 검증 손실 행렬의 크기를 담았다.

### 같은 설정으로 실행하기

저장된 모델을 사용할 때는 `complete_val2017_top32.yaml`로 평가 자료를 먼저 준비한다. 각 방법의 동일한 SAE와 대응 행렬을 지정하면 COCO·COCO-Stuff·Visual Genome의 진단값, 네 검색 자료의 정답 순위, 두 편집 자료의 쌍별 결과를 출력한다.

```sh
python -m mm_sae prepare configs/complete_val2017_top32.yaml
python -m mm_sae evaluate configs/complete_val2017_top32.yaml --sae "$SAE_DIR" --fit "$FIT_DIR"
```
