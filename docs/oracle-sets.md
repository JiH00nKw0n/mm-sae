# COCO 주석으로 특징 집합을 학습하고 검색을 평가한다

이 실험은 범주 주석을 사용해 이미지·텍스트에서 같은 범주를 예측하는 특징 집합을 만든다. 평가 시에는 activation만 입력하고 정답 이미지·캡션 쌍을 검색한다. 주석을 사용하지 않는 CCA와 비교하므로 지도 학습을 사용한 참고 실험이다. 주석을 예측하는 특징이 해당 개념 자체에만 반응한다고 보장하지 않으며, 정확한 의미 집합을 알고 있는 oracle이라고 부르지 않는다.

## 학습과 평가 자료를 분리한다

기존 COCO SAE와 저장된 activation을 사용한다. SAE를 다시 학습하거나 이미지를 다시 추론하지 않는다. 기존 대응 학습에 사용한 COCO train2017 이미지 94,630장으로만 특징 집합과 계수를 결정한다. 같은 이미지의 모든 캡션은 같은 분할에 속한다. 남은 학습 이미지 23,657장은 예약한 조정 자료이며 이번 고정 설정에서는 사용하지 않는다.

COCO val2017 이미지 5,000장과 캡션 25,014개에서 검색을 평가한다. 이전 분석에서 이미 확인한 검증 자료이므로 최종 미관측 시험이라고 부르지 않는다. 학습 중 값이 변한 원래 이미지 SAE 특징 906개와 텍스트 특징 437개를 사용한다. ‘전체 특징’도 이 범위를 뜻하며, 원래 4,096개 중 학습에서 상수인 특징은 포함하지 않는다.

이미지 표본에는 해당 이미지의 학습 캡션 수만큼 가중치를 준다. 따라서 기존 이미지·캡션 쌍을 사용한 학습 공분산과 같은 모집단을 사용한다. 입력 평균·표준편차도 기존 대응 학습의 값을 그대로 사용한다.

## 범주 정답을 두 방식으로 부여한다

이미지 정답은 모델의 중앙 자르기 영역에 해당 범주가 존재하는지 나타내는 COCO-Stuff 주석이다. 물체 80개와 배경 91개를 같은 순서의 171개 좌표로 사용한다. 범주별로 다른 특징 집합을 선택할 수 있고, 여러 범주가 같은 특징을 공유할 수 있다.

주 실험은 이미지에 부여된 COCO 범주 정답을 해당 이미지의 학습 캡션에도 부여한다. 텍스트는 문장에 생략된 범주까지 짝 이미지에 있는지 예측하도록 학습한다. 따라서 텍스트에 직접 언급된 의미와 동일한 정답은 아니다.

비교 조건은 이미지에는 같은 COCO 주석을 사용하고 텍스트에는 검토한 사전으로 찾은 캡션 내 언급 여부를 사용한다. 텍스트 주석은 사람이 문장마다 검수한 의미 정답이 아니다. 평가에서는 두 조건 모두 이미지 존재 AUROC와 텍스트 사전 언급 AUROC를 보고하고, 텍스트에서 이미지 범주를 예측한 AUROC도 별도로 보존한다.

## 적은 특징으로 범주 점수를 만든다

범주마다 이진 정답과 예측값 사이 평균 제곱오차에 계수 제곱 벌점 0.01을 더한 목적함수를 줄인다. 현재 집합에 특징 하나를 추가했을 때 목적함수를 가장 많이 낮추는 특징을 선택한다. 특징을 추가할 때 이미 선택한 특징의 가중치도 다시 구한다. 이 과정을 통해 1개·4개·8개·16개 특징을 사용하는 집합을 만들고, 전체 특징을 사용하는 릿지 회귀도 비교한다. 선택 과정은 결정적이며 전체 가능한 집합 중 최적해를 보장하지 않는다.

음수 계수도 허용한다. 범주별 출력은 선택한 activation의 가중합이며 확률이 아니다. 학습 평균을 제거하고 학습에서 예측값의 분산이 1이 되도록 양쪽 출력을 각각 보정한다. 분산이 0인 좌표는 0으로 남긴다. 범주별 예측값을 합쳐 171차원 벡터를 만든 뒤 코사인 유사도로 검색한다. 계수나 점수 방향을 평가 주석으로 다시 선택하지 않는다.

## 차원 수와 출력 보정을 맞춘다

CCA와 Sparse CCA의 앞 171개 공통 좌표도 평가한다. 이 좌표들은 학습 자료만으로 구한 순서이며 평가 성능으로 선택하지 않는다. 학습 예측 분산을 1로 맞춘 조건을 주 비교에 사용하고, 기존 좌표 크기를 유지한 조건도 별도로 남긴다. 기존 256차원 결과는 다른 차원의 참고값으로 표시한다.

양방향 Recall@1·5·10은 기존과 동일하게 계산한다. 이미지 검색에서는 그 이미지에 속한 캡션 중 하나가 순위 안에 있으면 정답이다. 텍스트 검색에서는 해당 캡션의 원래 이미지가 정답이다. 동점은 기존 계산처럼 작은 후보 행 번호를 우선한다. 모든 검색 질의와 후보를 유지한다.

## 정답 주석 벡터를 쓰는 참고값을 별도로 계산한다

이 참고 실험만 평가 이미지의 정답 범주 벡터를 이미지와 해당 캡션 양쪽에 직접 사용한다. 학습한 특징 집합의 성능도 아니고 일반적인 검색 성능 상한도 아니다. 범주 조합 자체가 이 평가 자료를 얼마나 구별하는지 확인하는 계산이다. 실제 캡션에 이미지의 모든 범주가 적혀 있다고 주장하지 않는다.

같은 주석 벡터를 가진 이미지가 여러 장이면 정답과 오답의 점수가 같아진다. 따라서 이 참고값은 동일 점수 후보의 순서를 균등하게 섞었을 때의 기대 Recall을 정확히 계산한다. 모든 범주가 없는 이미지는 다른 검색 조건과 동일하게 영벡터 실패로 유지한다.
