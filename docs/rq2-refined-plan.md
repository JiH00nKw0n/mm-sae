# RQ2의 특징 수와 모달리티 간 대응 구조 검증 계획

**RQ2는 한 개념에 특징 하나가 충분한지와 모달리티 간 특징을 1대1로 연결해도 충분한지를 구분해 검증한다.** 상위 5개 특징 목록이 다르다는 사실만으로 의미 구별이나 모달리티 간 대응이 개선됐다고 판단하지 않는다. 두 단계의 성능 비교를 거쳐 어느 제약이 실제 손실을 만드는지 확인한다. 이 문서는 실행 전 제안이며 새로운 RQ2 실험 결과를 포함하지 않는다.

권장 연구 질문은 다음과 같다.

> 같은 개념의 정보를 이미지와 텍스트 사이에 대응시킬 때, 개념당 특징 하나와 특징 간 1대1 연결로 충분한가? 충분하지 않다면 어떤 추가 특징이나 연결이 필요한가?

## 현재 결과에서 확인한 사실

기존 상위 5개 목록은 각 범주의 원본·가림 AUROC가 높은 특징을 정렬한 결과다. 서로 다른 범주가 같은 1위 특징을 선택해도 나머지 특징 목록은 달랐다. 그러나 추가 특징을 함께 사용한 분류 성능은 측정하지 않았다. 이미지 서핑보드의 2위부터 5위 특징 AUROC는 약 0.513–0.518로 낮았다. 이 사례는 여러 특징이 필요하다는 증거로 사용할 수 없다.

텍스트 흙·자갈·진흙·모래의 1위는 모두 1743번이고 각각의 가림 AUROC는 약 0.986, 0.938, 0.956, 0.900이었다. 같은 특징이 각 표현의 제거에 반응한다는 관찰이다. 그 특징 하나가 활성값의 크기로 네 범주를 구별할 가능성은 아직 검사하지 않았다. 여러 범주에 높은 가림 AUROC를 갖는다는 사실은 범주 간 구별력이 높다는 뜻이 아니다.

현재 RQ1에서 기준 범주의 이미지·텍스트 검증 AUROC가 모두 0.7 이상인 23개 범주만 보면, 같은 범주보다 점수가 높은 다른 상대가 있는 경우는 이미지 기준 1개, 텍스트 기준 0개였다. 따라서 대표의 약한 구별력과 대응 구조의 제약을 분리해야 한다. 반면 RQ2에서 처음부터 단일 특징 AUROC 0.7 미만을 모두 제외하면 여러 특징을 모아야 개념을 읽을 수 있는 경우까지 제외할 수 있다.

## 공통 조건

기존 이미지·텍스트 SAE와 이미지 흰색 가림, 텍스트 UNK 가림 방식은 유지한다. 특징 번호는 같은 SAE 안에서만 비교한다. 같은 특징이 여러 범주의 후보가 돼도 실제 좌표를 복제하지 않는다.

COCO train을 이미지 ID 기준으로 80% 학습용과 20% 조정용으로 나눈다. 한 이미지의 모든 캡션과 모든 가림 변형은 같은 집단에 둔다. 학습용 자료에서 특징을 선택하고 간단한 분류기·예측기의 계수를 학습한다. 조정용 자료에서 규제 강도와 사용할 특징을 확정한다. COCO val에서는 고정된 설정의 성능을 보고한다. val은 이전 분석에서도 살펴본 자료이므로 이번 결과는 탐색적 후속 검증으로 기술하며 완전히 보지 않은 최종 시험 자료라고 주장하지 않는다.

새 분할의 특징 선택에 조정용 자료가 섞이지 않도록, 학습용 표본의 가림 활성값으로 특징별 AUROC를 다시 계산한다. 기존 슬라이드의 특징 번호는 사례 설명에 사용하되 새 성능 비교의 선택 과정과 구분한다. 불확실성은 이미지 단위 재표집으로 계산한다. 동일 이미지의 여러 캡션을 독립 표본으로 세지 않는다.

단일 특징 AUROC를 이유로 범주를 일괄 제외하지 않는다. 전체 결과와 단일 특징의 구별력별 결과를 함께 보여준다. 구별력 구간은 조정용 표본에서 정하고 평가 자료의 성능을 보고 바꾸지 않는다. 유효한 표본이 없는 경우는 계산 불가로 남기며 0점으로 넣지 않는다. 표본 수가 적은 범주와 물체·배경의 구성도 공개한다.

## 실험 1. 추가 특징이 실제 개념 구별에 도움이 되는가

### 전체 범주의 개념 검출

각 범주에서 기존 방식대로 학습용 원본·가림 AUROC가 높은 특징 1개, 2개, 5개를 선택한다. 선택된 활성값에 작은 선형 분류기를 학습한다. 여기서 선형 분류기는 활성값에 가중치를 곱해 더한 값으로 범주의 존재 여부를 예측하는 모델이다.

평가는 가리지 않은 원본 자료에서 수행한다. 이미지의 정답은 모델 입력 영역의 픽셀 주석에 해당 범주가 있는지이고, 텍스트의 정답은 해당 문장에 범주 표현이 있는지다. 따라서 특징 선택에 사용한 가림 AUROC와 평가에 사용하는 개념 검출 AUROC는 서로 다른 지표다. 둘을 같은 이름의 성능으로 섞지 않는다.

다음 비교를 함께 둔다.

| 비교 조건 | 확인할 내용 |
| --- | --- |
| 가림 AUROC가 가장 높은 특징 하나를 사용한다. | 기존 대표 선택의 성능을 확인한다. |
| 개념 검출 과제에 가장 적합한 특징 하나를 별도로 고른다. | 대표를 잘못 골라서 다섯 개가 좋아 보이는지 확인한다. 모든 활성 특징을 후보로 두고 학습·조정용 자료에서 고른다. |
| 가림 AUROC 상위 2개와 5개를 함께 사용한다. | 여러 좌표의 정보가 단일 특징보다 개념 검출을 개선하는지 확인한다. |
| 기존 대표 하나에 활성 빈도가 비슷한 다른 특징 네 개를 더한다. | 개념 관련 특징을 더한 효과가 임의의 입력 수 증가보다 큰지 확인한다. 난수 시드와 반복 수는 평가 전에 고정한다. |

기존 대표보다 다섯 개가 좋아도, 별도로 찾은 좋은 특징 하나와 같으면 대표 선택의 문제로 해석한다. 좋은 단일 특징보다 여러 특징이 별도 자료에서 더 잘하면, 해당 과제와 분류기 범위에서 여러 특징의 추가 정보를 확인한 것이다. 개선이 없으면 특징 목록의 차이를 유용한 의미 차이로 주장하지 않는다.

### 같은 1위 특징을 공유하는 범주의 직접 구별

학습용 자료에서 같은 1위 특징을 공유하는 범주 쌍을 모두 고정한다. 원래 슬라이드의 텍스트 흙·자갈·진흙·모래는 사례로 보여주되 결과가 좋은 사례로 교체하지 않는다.

A와 B를 비교할 때 이미지는 A가 있고 B가 없는 표본과 B가 있고 A가 없는 표본을 사용한다. 텍스트는 A만 언급한 문장과 B만 언급한 문장을 사용한다. 두 범주가 함께 있거나 둘 다 없는 표본은 이 직접 구별 과제에서 제외한다. 문장별 별도 작업에는 이미지 단위 분할을 유지한다.

공유된 특징 하나, 두 범주의 상위 5개를 합친 후보 중 가장 좋은 특징 하나, 그 후보들을 함께 사용하는 조건을 비교한다. 중복 좌표는 한 번만 사용하므로 후보 수는 최대 10개이며 정확한 수를 보고한다. 전 활성 특징에서 찾은 단일 특징도 보조 기준으로 둔다. 같은 특징 번호라도 활성값의 크기가 범주를 구별할 수 있으므로 번호가 같다는 이유로 단일 특징의 성능을 0.5로 간주하지 않는다.

표현이 겹치거나 동의어인 범주 쌍은 별도로 표시한다. 사전 전체나 가림 규칙은 바꾸지 않고, 실제 표현과 주석만 점검한다. 이 과제에서 개선돼도 모달리티 간 다대다 대응을 입증한 것으로 해석하지 않는다.

## 실험 2. 모달리티 간 1대1 연결이 실제 정보를 잃는가

### 예측 대상과 자료

이미지에 범주 c가 있고 해당 캡션에도 c가 언급된 이미지·캡션 쌍을 사용한다. 캡션이 c를 언급하지 않은 사례는 주 분석과 별도로 보고한다. 언급이 없다는 이유로 활성값 자체를 0으로 만들지 않는다.

범주 c를 이미지와 텍스트에서 각각 가렸을 때의 변화를 구한다.

`이미지 변화 = 이미지 원본 활성값 − 이미지에서 c를 가린 활성값`

`텍스트 변화 = 텍스트 원본 활성값 − 텍스트에서 c를 가린 활성값`

이미지 변화로 텍스트 변화를 예측하고 반대 방향도 예측한다. 원본 활성값의 동시 변동만 설명하는 것보다, 같은 범주를 제거했을 때의 변화를 설명하는지에 초점을 맞춘다. 이는 입력 가림의 반응에 대한 평가이며 가림 면적, 토큰 수, 부수적인 문맥 변화가 완전히 제거된 인과 실험이라고 주장하지 않는다.

후보는 학습용 표본에서 고정한 범주별 상위 5개 특징의 합집합이다. 각 SAE에서 같은 번호는 하나의 좌표로만 남긴다. 예측할 목표 좌표와 사용할 수 있는 입력 좌표는 모든 비교 조건에서 같게 유지한다. 특히 입력 특징을 늘릴 때 목표 특징도 함께 늘리지 않는다. 여러 범주에 걸쳐 공통된 연결을 학습해, 공유 좌표를 범주마다 별개로 복제하여 1대1 제약을 피하지 않는다.

### 비교할 세 가지 연결 조건

| 연결 조건 | 한 목표 특징을 예측하는 방법 | 확인할 제약 |
| --- | --- | --- |
| 양쪽 모두 1대1로 제한한다. | 목표 특징마다 입력 특징 하나를 사용하고, 같은 입력 특징을 다른 목표에 재사용하지 못한다. | 두 모달리티의 좌표를 서로 독점적으로 짝짓는 제약을 확인한다. |
| 목표당 입력 하나를 쓰되 재사용을 허용한다. | 각 목표는 가장 적합한 입력 하나를 사용하며, 같은 입력이 여러 목표를 설명할 수 있다. | 하나의 입력 특징이 여러 목표 특징을 설명해야 하는지 확인한다. |
| 목표당 입력을 최대 2개 또는 5개까지 허용한다. | 같은 후보 집합에서 여러 입력을 조합하고 재사용도 허용한다. | 목표 하나를 설명하는 데 여러 입력의 조합이 필요한지 확인한다. |

모든 조건은 같은 표준화, 선형 예측식과 규제 강도 후보를 사용한다. 단일 연결도 계수의 크기와 절편을 학습한다. 단순히 두 좌표의 활성값을 같은 크기로 간주하지 않는다. 연결 선택은 학습·조정용 예측 성능을 기준으로 한다. 1대1 조건도 같은 기준의 최선 연결을 헝가리안 알고리즘으로 선택한다. 이 방식은 원본 상관점수로 고른 나쁜 연결 때문에 1대1 구조가 불리해지는 것을 줄이려는 분석용 비교다. 회귀 계수를 새로운 의미 대응 점수로 제안하는 실험이 아니다.

주 지표는 평가 자료에서의 R²다. R²는 평균 변화만 예측하는 기준과 비교해 활성 변화의 제곱오차를 얼마나 줄였는지를 나타낸다. 목표마다 학습 자료의 척도로 표준화하고, 세 조건 모두 동일한 목표와 표본에서 비교한다. 변화가 상수인 목표는 계산 불가로 표시한다. 원래 목표 좌표 수 차이 때문에 연결되지 않은 목표는 별도로 세고, 공통으로 연결 가능한 목표에서도 성능 차이를 확인한다.

이미지·텍스트 짝을 같은 범주 안에서 섞은 대조군과 활성 빈도가 비슷한 다른 특징 후보를 사용한 대조군을 함께 둔다. 전자는 범주마다 평균적으로 가림에 반응하는 정도만으로 얻는 이득과 실제 짝의 변화 예측을 구분한다. 대조군에서 비슷한 이득이 나면 의미 대응 구조의 증거로 사용하지 않는다.

두 번째 조건만으로 개선되면 입력 특징 재사용이 필요한 사례로 해석한다. 세 번째 조건이 두 번째보다 개선되면 목표를 설명하는 데 여러 입력을 조합할 이득이 있는 사례로 해석한다. 실험 1의 의미 구별, 실험 2의 변화 예측, 대조군 비교가 함께 지지하는 경우에만 해당 범위의 1대1 제약을 완화할 근거로 제시한다. 낮은 예측 성능만으로 상대 모달리티에 대응 특징이 없다고 결론 내리지 않는다.

## 최소 그림과 실행 순서

본문 그림은 두 개를 우선 목표로 한다. 그림 1은 특징 1개·2개·5개를 사용할 때의 개념 검출 성능과, 공유 특징을 가진 범주의 직접 구별 성능을 이미지·텍스트별로 보여준다. 그림 2는 세 연결 조건의 활성 변화 예측 성능을 두 방향에서 보여준다. 각 그림에 표본 수와 이미지 단위로 계산한 성능 차이의 불확실성을 넣는다. 그림 1만 개선되면 개념당 대표 하나의 한계만 주장하며, 그림 2까지 지지해야 모달리티 간 1대1 대응의 한계로 확장한다.

필요하면 사례 하나의 활성 반응과 연결을 세 번째 그림으로 추가한다. 전체 원시값, 물체·배경 구성, AUROC 구간, 유효 표본 수는 보조 표로 둔다. 작은 성능 차이의 신뢰구간이 0을 포함한다고 곧바로 한 특징으로 충분하다고 판정하지 않으며, 불확실한 결과로 남긴다.

먼저 실험 1을 저장된 원본·가림 활성값으로 수행한다. 공유 특징 쌍과 전체 범주를 포함하고 기존 사례만으로 일반화하지 않는다. 실험 2의 후보 범위를 결과가 좋은 평가 사례만으로 정하지 않도록 학습·조정용 자료에서 고정한다. 새로운 대규모 인코더 추론이나 SAE 학습은 필요하지 않으며, 작은 분류기와 예측기는 별도로 학습한다. 검증 자료에서 자갈과 진흙의 텍스트 가림 표본은 각각 11개뿐이므로 이 사례의 평가에는 큰 불확실성이 예상된다.
