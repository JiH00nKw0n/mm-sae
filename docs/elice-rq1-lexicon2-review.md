# 수정 사전을 사용하는 RQ1 재실행 설정

**사용자가 “서버 켰으니까 바뀐 dictionary로 다시 실험해줘.”라고 요청하여 재실행을 승인했다.** 실행 설정은 서버의 `/mnt/working/mm-sae/configs/elice-rerun.yaml`이며 새 결과는 `/mnt/working/mm-sae/runs/elice-rq1-lexicon2`에 저장한다. 기존 결과 `/mnt/working/mm-sae/runs/elice-rq1`은 보존한다. 실행 전에 최종 사전, 코드, 설정, 이 문서의 SHA-256 지문과 사용자의 승인 문구를 `/mnt/working/mm-sae/approvals/elice-rq1-lexicon2.json`에 기록한다.

**실험 조건 중 바뀌는 것은 캡션 표현 사전 하나다.** `/mnt/working/mm-sae/configs/concepts.reviewed.yaml`은 171개 범주의 번호와 이름을 유지하고 별칭을 기존 408개에서 3,110개로 수정한 최종 사전이다. 파일의 SHA-256은 `4869f0fec3a02c247db9d96a961fbaad74ef55b45a5456ebf3d97f43216f42a4`이다. 별칭 검토에는 train2017의 캡션 591,753개와 val2017의 캡션 25,014개를 모두 사용했다. 따라서 이번 val2017 결과는 사전 개발과 독립적인 검증 결과가 아니다. 계산 결과를 안전하게 재사용하는 기능은 실행 시간을 줄이기 위한 변경이며, 가림·특징 선택·상관계수·연결 알고리즘은 유지한다.

**CLIP과 두 SAE의 가중치는 재학습하지 않는다.** `reuse.sae_weights`가 이전 실행의 `models/image`와 `models/text`를 불러와 새 폴더에 저장하고, 텐서 단위로 완전히 같은지 확인한다. 하나라도 다르면 실행을 중단한다. 학습 단계의 인자는 기록을 위해 이전과 같게 유지하지만 실제 학습은 수행하지 않는다.

**이전 실행의 산출물은 검증을 통과한 것만 가져온다.** 각 단계가 실행되는 동안 아래 검사를 수행하며, 결과와 이유를 `runs/elice-rq1-lexicon2/reuse.json`에 남긴다. 완료 표식은 복사하지 않는다.

| 항목 | 처리 | 검사 |
| --- | --- | --- |
| 이미지 쪽 색인(존재 표지, 전체 이미지 표지, 면적) | 가져온다 | 이미지 번호 순서, 범주 번호 목록, 표지 기준 `model_input`, 인코더 리비전이 같고, 모든 이미지·주석 PNG의 SHA-256이 이전 기록과 같을 때 |
| 캡션 색인(표현 문자 범위, 가릴 토큰 위치, 언급 표지) | 새 사전으로 다시 만든다 | 해당 없음 |
| 원본 CLIP 표현 | 내용 주소 캐시에서 가져온다 | 인코더 설정, 이미지 파일 지문, 캡션 원문, 라이브러리 버전으로 만든 키가 같을 때 |
| 원본 활성값 | 가져온다 | SAE 가중치 지문과 원본 표현 파일의 바이트가 같을 때 |
| 이미지 객체 가림 표현·활성값 | 가져온다 | 가릴 이미지 행, 해당 이미지·주석 지문, 가림 색, 인코더가 같을 때 |
| 텍스트 가림 표현 | 캡션 행 단위로 가져온다 | 캡션 번호, 원문, 가릴 토큰 위치가 정확히 같은 행만 복사하고 나머지 행은 다시 부호화한다 |
| 원본 상관행렬 | 다시 계산한다 | 이전 행렬과의 최대 절대 차이를 기록한다 |
| 텍스트 대표 특징, 연결 판정, 객체 제거 실험, 그림 | 다시 계산한다 | 텍스트 주석에 따라 달라지므로 재사용하지 않는다 |

**사전 변경이 바꾸는 것과 바꾸지 않는 것.** 이미지 대표 특징의 선택 AUROC는 이미지 가림 결과만 쓰므로 이전과 같아야 하며, 다르면 오류로 본다. 텍스트 대표 특징은 달라질 수 있다. 원본 상관행렬과 두 연결 방식의 배정은 활성값만 쓰므로 이전과 같아야 하고, 연결의 같은 객체·다른 객체 판정은 새 대표에 따라 달라진다. 객체 제거 실험은 새 텍스트 주석과 가림 위치로 다시 수행한다.

**실험 1, 2, 3과 기존 보고서를 모두 다시 만든다.** COCO2017 train의 전체 이미지와 캡션으로 상관계수와 대표 특징을 계산한다. 실험 1은 자기 자신을 제외한 범주 조합을 이미지 주석 상관계수의 0.2 간격으로 나누어 대표 특징의 이미지·텍스트 활성값 상관을 평가한다. 실험 2는 Greedy와 헝가리안 연결의 같은 객체·다른 객체·판정 불가·미연결 수를 평가한다. 실험 3은 기존과 같은 객체 제거와 대조 조건을 5회 반복하여 점수와 연결의 변화를 평가한다. 이미지 가림은 흰색이며 텍스트 가림은 기존 UNK 토큰 ID를 사용한다. 임의의 AUROC 하한이나 범주 조합 표본 수 제한은 추가하지 않는다.

**사전 수정으로 검출 수가 늘었지만 이를 정확도 향상으로 단정하지 않는다.** 학습 캡션에서 공 표현을 찾은 수는 2개에서 11,520개, 텔레비전·모니터 표현은 5,747개에서 7,799개로 늘었다. 오렌지 과일은 색상 오탐을 줄이기 위해 단독 `orange`를 제외하여 6,419개에서 1,878개로 줄었으며, 단순한 단수형 과일 표현을 놓치는 한계가 남는다. 배경·재료 범주와 복합어의 문맥 오류도 남는다. `mouse pad and mouse`에서는 두 `mouse`만 가리고 `pad`는 남긴다. 문맥 예외나 캡션 삭제 규칙을 추가하지 않는다. 기존 겹침 처리 때문에 학습 캡션 31개에서 62개 범주·캡션 조합의 가림 위치를 확정하지 못한 사례도 유지한다.

**진행률과 현재 작업의 예상 남은 시간은 10초마다 기록한다.** 서버에서 `/mnt/working/mm-sae/.venv/bin/python -m mm_sae status --run-dir /mnt/working/mm-sae/runs/elice-rq1-lexicon2`로 확인한다. 아직 측정하지 않은 후속 단계의 시간을 전체 ETA로 단정하지 않는다. 완료 후 두 SAE의 가중치, 원본 상관행렬, 이미지 대표 특징, 두 방식의 원본 연결이 기존 실행과 동일한지 확인하고 새 결과를 로컬로 가져온다.
