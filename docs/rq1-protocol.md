# RQ1 실험 규약

RQ1은 이미지·텍스트 특징의 동시 활성화 상관계수가 객체 대응을 얼마나 잘 반영하며, 서로 다른 객체의 동시 등장 때문에 실제 연결이 틀리는지를 검사한다. 학습된 모델을 고정한 채 원본 점수, 실제 연결, 객체 제거 후 변화의 세 수준에서 평가한다. 아래 내용은 구현한 절차이며 기대하는 결과를 측정 결과로 제시하지 않는다.

**공식 COCO2017 학습 자료에서 두 SAE를 따로 학습한다.** 이미지별 CLIP 벡터 하나와 캡션별 CLIP 벡터 하나를 구해 각각 길이가 1이 되도록 정규화한다. 이미지 SAE와 텍스트 SAE는 매개변수를 공유하지 않는다. 기본값은 각 4,096개 특징 중 활성값이 큰 최대 8개를 남기는 TopK 방식이다. 학습은 Hugging Face Trainer가 수행하며, 학습 후 분석에서는 CLIP과 SAE의 매개변수를 고정한다.

기본 설정은 학습, 특징 선택, 상관 계산에 `train2017`을 사용한다. `val2017`에서는 이미 고른 특징의 원본·제거 반응을 확인한다. 같은 이미지의 캡션과 편집본은 같은 분할에 속한다. 학습 자료에서 계산한 연결 비율은 그 자료에 대한 진단 값이다. 새로운 자료에서의 대응 성능으로 보고하지 않는다.

**이미지 객체 표지는 모델이 실제로 보는 영역을 기준으로 만든다.** COCO-Stuff의 정수 PNG에 CLIP과 같은 크기 조정과 중앙 잘라내기를 적용한다. 이때 범주 번호가 섞이지 않도록 주석에는 최근접 보간을 쓴다. 전처리된 주석 안에 범주가 있으면 존재 표지는 1, 없으면 0이다. 전체 이미지 주석의 존재 여부도 별도로 저장하며 `label_scope: full_image`로 기준을 바꿀 수 있다.

텍스트 객체 표지는 해당 캡션에 범주 표현이 있는지를 나타낸다. 이미지에 객체가 있다는 이유로 텍스트에 같은 표지를 주지 않는다. 기본 범주명·동의어 규칙과 사람이 검토한 주석 입력을 구별해 기록한다. 의미 단위는 COCO-Stuff의 객체·배경 범주이며, 모든 종류의 의미 대응을 포괄하지 않는다.

**각 개념의 대표 특징은 원본과 해당 개념 제거본의 AUROC가 가장 큰 특징이다.** 개념을 c, 이미지 특징을 f라고 하자. c가 존재하는 모든 이미지에서 f의 원본 활성값을 양성 점수로, 같은 이미지에서 c의 주석 영역을 전부 흰색 RGB(255, 255, 255)으로 채운 뒤의 활성값을 음성 점수로 둔다. 텍스트에서도 c의 표현이 있는 원문과 그 표현을 모두 삭제한 문장을 사용한다.

원본 점수 N개와 제거본 점수 N개를 각각 서로 교차 비교한다. 원본이 더 크면 1, 동점이면 0.5, 더 작으면 0을 주고 N²개 비교의 평균을 구한 것이 표준 AUROC다. 동일 이미지 안에서 활성값이 감소한 비율과는 다른 지표다. 코드에서는 0인 활성값의 동점을 정확히 합산해 같은 값을 계산한다. 별도 분류기를 학습하지 않는다.

각 c에 대해 이미지 대표 i(c), 텍스트 대표 j(c)를 하나씩 선택한다. 원본 상관 계산 자료에서 한 번이라도 활성화된 특징을 대상으로 최대 AUROC를 고른다. 동점이면 특징 번호가 작은 것을 선택하고 동점 수를 남긴다. AUROC 0.8 같은 문턱은 두지 않는다. 해당 개념의 원본·제거 쌍이 없으면 대표를 선택할 수 없다고 기록한다.

같은 절차로 고른 대표를 `val2017`에서 바꾸지 않고 평가한다. AUROC, 같은 입력에서 감소한 비율과 평균 감소량, 원본 활성 빈도, 표본 수를 저장한다. 여러 개념이 같은 특징을 대표로 고를 수도 있다. 최고 AUROC라는 사실만으로 그 특징을 강한 단일 객체 특징이라고 단정하지 않는다.

**원본 상관행렬은 전체 특징을 대상으로 계산한다.** 행 i는 이미지 특징, 열 j는 텍스트 특징이다. 각 캡션에 해당 이미지의 활성값을 연결하고, 전체 캡션 행에서 두 연속 활성값의 부호 있는 피어슨 상관계수 C[i,j]를 계산한다. 이미지에 캡션이 다섯 개 있으면 상관 계산에서는 해당 이미지 활성값이 다섯 행에 들어간다. 이미지 SAE 학습에서 이미지를 다섯 번 중복하는 것과는 별개의 처리다.

활성값이 상수인 특징의 상관계수는 정의되지 않는다. 수치 배열에는 계산용 0을 넣되 유효 여부 배열을 함께 저장한다. 이 0을 낮지만 유효한 점수로 해석하지 않는다.

연결 최적화에서도 미정의 점수를 제외한다. 원본에서 정한 후보 특징 번호는 보존하지만, 각 조건에서 상수가 된 특징에는 유효한 연결이 없다. 상수가 된 이미지 대표는 연결 없이 상관 미정의로 분모에 남긴다. 따라서 저장용 0이 유효한 음수 점수를 밀어내지 않는다.

**첫 번째 실험은 서로 다른 객체의 동시 등장과 특징 점수의 관계를 본다.** 각 이미지에서 a와 b가 있는지를 나타내는 두 이진 표지의 피어슨 상관계수를 계산한다. 이는 이진 표지에 대한 파이 계수와 같다. 이 계산은 이미지별 한 번 수행하며 캡션 수로 이미지를 반복하지 않는다.

평가할 조합은 이미지 대표 i(a)와 텍스트 대표 j(b)가 존재하는 모든 순서 있는 개념 조합 (a,b)이며 a=b는 제외한다. 예를 들어 사람 이미지 대표와 자전거 텍스트 대표, 자전거 이미지 대표와 사람 텍스트 대표는 서로 다른 두 조합이다. 같은 특징이 여러 개념의 대표라면 개념 조합도 각각 기록한다. 구간별로 일부만 추출하지 않는다.

주석 상관계수를 −1부터 1까지 0.2 간격으로 나눈다. 각 구간은 왼쪽 경계를 포함하고 오른쪽 경계를 제외하며 마지막 구간만 1을 포함한다. 각 구간에 들어간 모든 조합의 C[i(a),j(b)] 평균과 모집단 표준편차를 계산한다. 표준편차의 분모는 해당 구간의 조합 수 N이며 N−1이 아니다. 상관이 정의되지 않는 표지나 특징은 이유를 남기고 구간 통계에 넣지 않는다.

그림 1은 이 평균과 표준편차, 조합 수를 표시한다. 전체 값은 `all_ordered_concept_pairs.csv`에 저장하며, 이미지 a의 존재와 캡션 b의 언급 사이 상관계수도 함께 저장한다. 이 그림은 다른 객체의 동시 등장과 특징 상관의 관계를 보여준다. 같은 객체 조합을 제외했으므로 이 그림 자체가 의미 일치 분류 정확도는 아니다.

**두 번째 실험은 전체 특징으로 연결한 뒤 대표 특징의 실제 상대를 평가한다.** Greedy는 각 이미지 특징에서 상관계수가 가장 큰 텍스트 특징 하나를 고른다. 여러 이미지 특징이 같은 텍스트 특징을 선택할 수 있다. 헝가리안 방식은 연결 점수 합이 최대가 되도록 일대일 대응을 구한다. 양쪽 특징 수가 다르면 일부 특징은 연결되지 않는다. 두 방식 모두 원본 자료에서 한 번이라도 활성화된 전체 특징을 후보로 쓴다.

평가 분모는 대표로 선택된 고유 이미지 특징의 수이며 두 방식에서 같다. 이미지 특징과 연결된 텍스트 특징이 각각 정확히 하나의 개념 대표이고 그 개념이 같으면 일치, 서로 다르면 불일치다. 대표가 여러 개념을 공유하거나 상대가 어떤 개념의 대표도 아니면 판정 불가다. 상관이 정의되지 않는 경우와 연결되지 않은 경우도 구분해 남긴다. 대표가 없는 특징을 곧바로 오답으로 세지 않는다.

그림 2는 두 방식의 일치·불일치·판정 불가·상관 미정의·미연결 비율을 보여준다. 전체 특징의 배정과 대표 행별 결과도 저장한다. 단일 객체 대표에는 같은 객체 텍스트 대표의 점수를 추가해 실제 선택 상대와 비교할 수 있게 한다. 모든 특징에 의미 정답이 있는 것은 아니므로 이 비율을 전체 SAE 특징의 의미 정확도로 부르지 않는다.

**세 번째 실험은 원래 틀린 연결을 만든 객체 관계를 약화한다.** 두 방식 중 적어도 하나가 이미지 a 대표를 다른 객체 b의 텍스트 대표와 연결한 모든 (a,b)의 합집합을 대상으로 한다. 먼저 a가 있을 때 b가 있는 비율 p1과 a가 없을 때 b가 있는 비율 p0를 구한다. p1>p0>0인 경우에만 b를 일부 남기면서 양의 동시 등장 관계를 없애는 제거 수를 정의할 수 있다.

a와 b가 함께 있는 이미지 중에서 b를 제거할 비율은 q=1−p0/p1이다. q에 동시 등장 이미지 수를 곱해 가장 가까운 정수로 반올림한다. 예를 들어 p1=0.8, p0=0.2이면 a와 함께 있는 b의 75%를 제거한다. 반올림 후 달성한 조건부 비율을 실제로 계산해 보고한다. p0가 0이거나 편집 가능한 이미지가 부족하면 원래 오류를 유지하면서 검사 불가 이유를 기록한다.

각 오류 조합에서 원본, 같은 양의 무작위 제거, 동시 등장에 따른 제거를 비교한다. 동시 등장에 따른 제거는 a와 b가 함께 있는 이미지에서 정해진 수를 무작위 선택해 b만 가린다. 무작위 대조는 b가 있는 전체 이미지에서 선택한다. 각 이미지에 속한 캡션에서 b가 언급되면 모두 해당 표현을 삭제하고, b가 없는 캡션은 그대로 둔다. 표현 삭제가 불가능한 이미지 묶음은 편집 대상으로 사용하지 않는다.

대조 조건은 이미지당 전체 캡션 수, b를 언급한 캡션 수, b 영역 면적의 분위 구간별로 조건부 제거와 같은 수를 선택한다. 따라서 이미지 제거 수와 캡션 편집 수는 정확히 같고, 가림 면적은 같은 구간 안에서 비교한다. 실제 면적 차이와 두 조건에서 겹친 이미지 수를 남긴다. 면적 분위 구간의 기본 개수는 5이며 설정으로 바꿀 수 있다.

모든 조건은 원래 자료의 행을 유지한다. 편집한 입력의 활성값만 교체하고 전체 상관행렬과 두 연결 방식을 다시 계산한다. 원본에서 정한 특징 후보 집합과 대표 번호는 바꾸지 않는다. 기본 5회 반복은 제거 대상 선택의 반복이며 모델 재학습이 아니다.

그림 3은 네 부분으로 구성한다. 같은 객체 대표와 원래 잘못된 대표의 평균 상관계수, 원래 오류의 연결 회복률, 원래 올바른 다른 연결이 손상된 비율, 편집 이미지당 꺼진 특징 수를 비교한다. 오류가 판정 불가로 바뀐 경우는 회복이 아니다. 올바른 연결이 새 오답으로 바뀐 경우와 판정 불가로 바뀐 경우를 원자료에서 구분한다. 각 방법의 회복률 분모는 검사 가능한 사례 중 해당 방법이 원래 틀린 행이다.

그림 3의 점수 평균은 세 조건 모두에서 같은 객체 상대와 잘못된 상대의 점수가 정의되는 공통 사례·반복만 사용한다. 두 선과 세 조건에서 같은 집합을 비교하고 사용한 수와 전체 수를 그림에 표시한다. 조건별 미정의 수와 제외된 사례·반복은 `/workspace/runs/coco-rq1/rq1/experiment3/paired_score_summary.json`에 남긴다. 이 제한은 점수 평균에만 적용하며 회복률과 손상률에는 검사 가능한 전체 사례를 유지한다.

꺼진 특징은 원본에서 양수였고 편집 후 0인 특징이다. 새로 켜진 특징과 연속 활성값의 변화량도 별도로 저장한다. 전후 양수 특징이 모두 8개이면 총 활성 개수의 차이는 0이어도 서로 다른 특징으로 교체될 수 있다. 이 때문에 총개수의 차이만 세지 않는다.

각 (a,b)마다 별도 편집 자료와 상관행렬이 생긴다. 그림 3의 평균은 이런 개별 제거 검사의 요약이며 하나의 개선된 전역 대응 방법의 정확도가 아니다. 무작위 제거보다 잘못된 점수가 낮아지고 올바른 연결이 더 자주 회복되면서 기존 올바른 연결이 유지될 때, 해당 객체의 입력상 동시 등장 관계가 일부 오류에 기여한다는 해석을 지지한다.

**본문 그림은 세 개이며 별도 본문 표는 필요하지 않다.** 그림별 CSV와 JSON에는 전체 조합, 분모, 판정 불가 사례와 반복별 값을 보존한다. 그림 1의 오차 막대는 조합 간 표준편차이며 신뢰구간이 아니다. 다른 그림은 고정한 대표와 원본 오류에서 계산한 기술 통계다. 표본 재추출 신뢰구간이나 여러 모델 학습 시드의 변동을 구현했다고 주장하지 않는다.

객체 제거 실험의 중간 전체 행렬을 모두 보존하면 오류 조합 수에 비례해 저장 공간이 크게 늘어난다. 기본값은 전체 행렬을 매번 계산하되 배정, 비교 점수, 편집 이미지 식별자와 결과만 보존한다. `save_intervention_panels: true`이면 중간 전체 행렬도 저장한다. 원본 전체 행렬과 원본·편집 활성값은 기본값에서도 저장한다.

흰색 가림은 배경을 복원하는 생성형 인페인팅이 아니다. 객체 윤곽이나 주변 문맥이 남을 수 있고, 문장 삭제는 문법과 문맥을 바꿀 수 있다. 현재 구현의 무작위 대조는 동일 객체의 제거 양을 맞추지만 목표 객체를 남긴 채 같은 모양의 다른 영역을 가리는 대조는 포함하지 않는다. 따라서 흰색 자체의 효과와 순수한 의미 제거의 효과를 완전히 분리했다고 주장하지 않는다. 대표 반응과 문장 주석의 신뢰도도 함께 확인한 뒤 논문 주장의 범위를 정해야 한다.
