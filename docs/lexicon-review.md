# 캡션 사전 검토 결과

**171개 범주의 사전 검토와 전체 616,767개 캡션 비교를 마쳤다.** 사전에 등록한 표현은 기존 408개에서 3,110개가 됐다. SAE 학습과 RQ1 실험은 재실행하지 않았다.

검토할 파일은 [최종 사전](/Users/jihoonkwon/Desktop/projects/research/MM-SAE/mm-sae/configs/concepts.reviewed.yaml)이다. 각 범주의 `id`와 `name`은 그대로 두고 `aliases`만 정리했다. 원본 사전과 기존 글자 검색·가림 코드는 변경하지 않았다.

COCO2017 학습 캡션 591,753개와 검증 캡션 25,014개를 모두 비교했다. 다음 표는 학습 캡션에서 각 범주의 표현을 찾은 횟수다. 한 문장에 같은 범주가 여러 번 나와도 한 번으로 센다. 실제 객체를 정확하게 찾은 비율을 뜻하지는 않는다.

| 검출한 범주 | 기존 사전으로 찾은 캡션 수 | 검토한 사전으로 찾은 캡션 수 | 바뀐 이유 |
| --- | ---: | ---: | --- |
| 공을 뜻하는 sports ball | 2 | 11,520 | `ball`, `balls`와 실제로 확인한 표현을 추가했다. |
| 텔레비전·모니터를 뜻하는 tv | 5,747 | 7,799 | COCO 범주의 범위를 고려해 `monitor`, `monitors`를 포함했다. |
| 오븐·조리기기를 뜻하는 oven | 3,083 | 5,623 | `stove`, `stoves`를 일반 가구 대신 이 범주에 배정했다. |
| 오렌지 과일을 뜻하는 orange | 6,419 | 1,878 | 색을 뜻하는 사용이 많아 단독 `orange`를 제외하고 복수형과 과일을 명시한 표현을 남겼다. |

**공의 사전 누락은 크게 줄었다.** 모델이 보는 이미지 영역에 공 주석이 있는 캡션만 보아도, 기존 사전은 2개를 찾았고 검토한 사전은 6,793개를 찾았다. 이미지에 주석이 있다는 이유로 텍스트에도 공이 있다고 판정하지는 않았다.

**단독 `orange`를 제외한 선택은 검토가 필요하다.** 색상 표현을 과일로 잘못 잡는 문제를 줄이지만, 과일을 단순히 `an orange`라고만 쓴 문장도 놓친다. `oranges`, `orange slice`, `peeled orange` 등은 남겼다. 문맥 판정 규칙은 추가하지 않았다.

자동으로 제안된 표현을 그대로 넣지는 않았다. 자동차 후보 `coupe`는 37개 캡션 중 36개가 `couple`의 오타여서 제외했다. `laundry`는 세탁실·바구니·기계를 뜻하는 사용이 많아 의류 범주에서 제외했다. 식물 후보 `herbs`와 단독 `wheat`는 음식 재료를 가리키는 사용이 많아 제외했고, `wheat field`처럼 식물을 명시한 표현은 남겼다.

**텍스트 가림은 요청한 단순 사전 방식으로 유지했다.** `A desk with a keyboard, mouse pad and mouse.`에서는 두 곳의 `mouse`만 가림 대상으로 잡히고 `pad`는 남는다. 실제 모델 입력에는 기존과 같이 미등록 단어를 나타내는 UNK 토큰의 ID를 사용한다. 문맥 예외, 가릴 구절의 자동 확장, 캡션 삭제는 추가하지 않았다.

기존 검색기가 서로 겹치는 표현을 처리하는 규칙도 유지했다. `traffic light pole`에서 `traffic light`와 `light pole`이 부분적으로 겹치는 경우처럼, 학습 캡션 31개에서는 두 범주의 가림 위치를 확정하지 못했다. 범주·캡션 조합으로는 62건이다. 해당 사례는 그대로 기록했으며 이를 없애기 위해 새 규칙을 넣지는 않았다.

후보 수집에는 보존된 Claude 보고서 59개와 Luna 작업 1,185개의 결과를 사용했다. 이어 259개 작업으로 의미를 재검토하고 최종 표현을 선택했다. 모델의 원시 답변에서 해당 작업에 제공된 캡션과 대응하지 않는 인용 251건은 정규화된 근거에서 제외했다. 채택한 표현과 관련된 인용 오류는 실제 캡션을 별도로 대조했다. 이 사전은 모든 문장을 사람이 의미 주석한 정답 자료가 아니다. 배경·재료 범주의 경계와 복합어의 부수적 오류는 남아 있다.

Ruff와 Pyright 검사를 통과했고, 관련 테스트 24개도 통과했다. 전체 캡션 비교에는 258.1초가 걸렸다. 범주마다 같은 표현을 중복 배정한 경우는 없었다. 사전으로 찾는 캡션이 늘었다는 결과만으로 coactivation 대응의 정확도가 바뀌었다고 결론 내릴 수는 없다. 사용자가 사전을 확인한 뒤 기존 SAE를 재학습하지 않고 RQ1을 다시 평가한다. 기존 원본 특징과 모델은 재사용하되, 가리는 토큰 위치가 달라진 텍스트의 계산은 다시 해야 한다.
