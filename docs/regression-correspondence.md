# 고정한 SAE 특징의 회귀 대응 점수 비교

이 분석은 2026년 8월 31일 제안서의 양방향 릿지 회귀 평균을 기존 공동 활성값 상관계수와 비교한다. SAE 가중치, 대표 특징 번호, 사전, 원본 이미지·캡션은 바꾸지 않는다. 두 점수의 단위가 다르므로 계수가 작아진 것 자체를 개선으로 판정하지 않는다. 같은 범주보다 높은 다른 범주의 수와 해당 상대가 하나 이상 있는 범주의 수를 함께 평가한다.

이미지의 표준화된 SAE 활성값 행렬을 X, 텍스트의 표준화된 활성값 행렬을 Y라고 한다. 기존 점수는 C = XᵀY/N이다. 이미지 특징 전체로 텍스트 특징을 예측하는 계수는 A = (XᵀX/N + λI)⁻¹C이며, 반대 방향의 계수는 B = (YᵀY/N + λI)⁻¹Cᵀ이다. 제안 점수는 (A + Bᵀ)/2이다. 두 방향의 λ는 별도로 고른다. 역행렬을 직접 만들지 않고 대칭 행렬의 고유값 분해로 계산한다. 모든 표본에서 일정한 특징은 제외하고 나머지 특징 전체를 회귀에 사용한다. 171개 범주의 대표 특징만으로 회귀하지 않는다.

규제 강도 선택에는 COCO train 이미지의 20%를 따로 떼어 사용한다. 나머지 80%로 평균·표준편차와 회귀 계수를 추정한 뒤, 남겨 둔 이미지에 연결된 캡션에서 표준화 활성값 예측 오차를 계산한다. 같은 이미지의 캡션은 서로 다른 분할에 들어가지 않는다. 각 방향의 평균 예측 오차가 가장 작은 λ를 고른 뒤 전체 train에서 점수를 다시 추정한다. 범주 이름, 주석 상관계수, 의미 대응 순위는 λ 선택에 사용하지 않는다. SAE 자체는 기존 train 전체로 이미 학습된 상태이므로 이 분할은 회귀 추정만을 위한 분할이다.

COCO val은 두 용도로 명확히 구분해서 사용한다. 첫째, train에서 고정한 회귀 계수와 표준화 통계로 val 활성값을 예측해 오차를 계산한다. 둘째, 동일한 λ와 대표 특징 번호를 유지하면서 val만으로 점수행렬을 별도로 추정해 순위 양상의 재현성을 확인한다. 두 번째 계산을 고정된 회귀 모델의 시험 성능이라고 부르지 않는다.

이미지 기준 범주 A에서는 이미지 A·텍스트 B의 점수를 이미지 A·텍스트 A와 비교한다. 텍스트 기준 범주 A에서는 이미지 B·텍스트 A의 점수를 이미지 A·텍스트 A와 비교한다. 두 방향 모두 나머지 170개 범주를 비교한다. 동점은 초과에 포함하지 않는다. 대표 특징 번호가 겹친 범주도 기존 실험과 같이 남긴다. AUROC에 따른 보조 분석은 val에서 측정한 이미지·텍스트 대표 AUROC 중 작은 값으로 기준 범주를 나누며, 비교 상대 170개는 줄이지 않는다. val에 가림 표본이 없는 범주는 AUROC 분석에서 계산 불가로 남긴다.

주석 상관의 구간은 기존 전체 train의 이미지·캡션 관측을 기준으로 0.2 간격을 사용한다. 캡션 하나가 관측 하나이며 같은 이미지의 활성값은 캡션 수만큼 반복된다. 표본의 비중을 조정하거나 캡션 누락을 제외하지 않는다. 따라서 이 분석은 앞서 논의한 캡션 누락 통제 실험의 결과가 아니다. 인간이 검수한 의미 정답이 아니라 기존 가림 AUROC 대표를 기준으로 한 탐색적 진단이다.

```bash
cd /Users/jihoonkwon/Desktop/projects/research/MM-SAE/mm-sae
PYTHONPATH=src OPENBLAS_NUM_THREADS=4 VECLIB_MAXIMUM_THREADS=4 OMP_NUM_THREADS=4 .venv/bin/python scripts/analyze_regression_correspondence.py --config configs/regression-cached.yaml
```

이 명령은 새 모델 추론이나 SAE 학습을 하지 않는다. 출력 폴더의 `progress.json`에 단계별 진행 상태를 기록한다. `scores.npz`에 활성 특징 번호와 전체 점수행렬을 저장하고, `per_category.csv`와 `per_pair.csv`에 모든 비교를 저장한다. `penalty_tuning.csv`는 규제 강도를 선택한 예측 오차이며 `penalty_sensitivity.csv`는 선택 이후의 민감도 분석이다. `heldout_prediction.csv`는 고정 모델의 val 예측 오차이고 `heldout_score_replication.csv`는 val에서 별도로 추정한 점수의 요약이다. 입력과 코드의 해시는 `manifest.json`에 기록한다.

회귀 계산은 직접 푼 정규방정식과 비교하고, 고정된 학습 평균으로 계산한 시험 오차를 표본별 직접 예측 오차와 비교하는 테스트를 둔다. 같은 모달리티 안의 특징 상관이 항등행렬이고 규제가 없을 때 기존 상관점수와 일치하는지도 검사한다. 실제 자료에서는 기존 상관행렬과의 일치, 정규방정식 잔차, 독립적으로 집계한 양방향 순위와 분모를 확인한다. 단순한 양의 상수배로 점수를 줄인 대조군에서는 순위가 그대로인지 확인한다.
