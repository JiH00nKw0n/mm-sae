# 특징 선택 기준의 비교

고정한 이미지·텍스트 SAE에서 개념에 대응하는 좌표를 고르는 기준만 바꾸어 이전 실험을 반복한다. 사용자가 2026년 9월 29일 실행과 슬라이드 반영을 요청했다. SAE나 임베딩 모델을 다시 학습하지 않는다.

| 선택 기준 | 계산 방법 |
|---|---|
| 원본·가림 AUROC | 기존 학습용 원본과 가림본 사이의 전체 순위 비교로 좌표를 고른다. 동점에는 특징 번호가 작은 좌표를 먼저 고른다. |
| 가림 전후 평균 차이 | 같은 입력의 원본 활성값에서 해당 범주를 가린 활성값을 빼고, 학습용 입력에 대해 평균한다. 부호를 유지해 큰 값부터 고른다. 활성값을 임의로 재정규화하지 않는다. |
| 단일 좌표 분류 손실 | 원본의 범주 존재 여부를 예측하는 로지스틱 회귀를 좌표마다 독립적으로 학습한다. 조정 자료에서 교차엔트로피 손실이 작은 좌표를 고른다. 희소화 후 실제 SAE 좌표를 사용한다. 희소화 전 좌표를 사용한 「Scaling and evaluating sparse autoencoders」의 동일 재현이라고 부르지 않는다. |
| 개념 분류기 기여도 | 원본 임베딩으로 개념 존재 분류기를 학습한다. 각 SAE 좌표의 양성·음성 평균 활성값 차이에, 해당 디코더 방향과 분류기 계수의 내적을 곱한다. 부호를 유지해 높은 값부터 고른다. 분류기 입력을 표준화한 효과를 계수에서 환산한다. |

두 SAE에서 각 복원 방향의 길이를 확인했다. 모든 좌표의 길이가 부동소수점 오차 범위에서 1이었다. 따라서 평균 활성값 감소량은 이 고정된 복원 방향의 단위를 기준으로 비교한다.

선택 점수와 최종 평가 점수를 구분한다. 개념 예측과 가림 구별의 평가 지표는 기존과 동일한 AUROC로 유지한다. 단일 좌표 분류 손실은 개념이 없을 때 활성값이 큰 좌표를 선택할 수도 있다. 개념 분류기 기여도도 평균 활성값 차이와 분류기 방향 기여도가 모두 음수이면 양의 점수를 부여한다. 따라서 회귀계수의 부호와 양성·음성 수를 저장한다. 원본 상관계수에는 선택한 좌표의 실제 SAE 활성값을 그대로 사용한다. 상관점수를 유리하게 만들기 위해 좌표의 부호를 뒤집지 않는다.

COCO train의 이미지 ID를 기존과 동일하게 80% 학습용, 20% 조정용으로 나눈다. 같은 이미지의 모든 캡션과 가림본은 같은 분할에 둔다. val은 좌표 선택에 사용하지 않는다. 텍스트 존재 라벨은 수정한 사전의 언급 여부다. 가림 자료에서는 해당 표현을 실제로 가린 문장만 사용한다. 임의의 AUROC 하한이나 결과에 따른 범주 제외는 추가하지 않는다. 분류기의 정규화 강도와 1·2·4·5·8개 특징 비교, 무작위 대조, 이미지 단위 1,000회 재표집은 기존 설정을 유지한다.

9월 16일에 발표한 RQ1의 질문을 train 전체에서 다시 계산하고, 9월 28일의 RQ1 확장·원래 RQ2·수정 RQ2·이미지 표현 진단은 val에서 평가한다. 두 표본을 섞지 않는다. 이번 train 재평가도 네 선택 기준에 동일한 80/20 선택 분할을 적용하므로, train 전체로 좌표를 골랐던 9월 16일의 원본 수치와 구분한다. 기존 발표 수치는 그대로 보존하고, 재평가의 AUROC 기준을 세 추가 기준의 직접 비교 대상으로 삼는다.

여러 특징의 가중합과 분류기 학습 방식은 기존 구현을 유지한다. 상관계수는 두 방향에서 평가하고, 양의 주석 상관만 원래 범주별 등장률을 유지한 채 쌍별로 0이 되도록 재가중한다. 네 집단이 없어 계산할 수 없는 경우는 결측으로 표시한다. 범주와 범주 쌍의 분포는 네 기준 모두에서 계산 가능한 공통 표본으로 비교하고, 각 기준의 전체 표본 수와 제외 수를 별도로 기록한다. 같은 1위 좌표를 공유하는 범주 쌍은 선택 기준에 따라 달라지므로, 기준별 집단과 공통 집단을 구분한다. 상대 활성값 예측의 목표 좌표도 선택 기준에 따라 달라지므로, 기준 간 R²를 같은 목표에 대한 우열로 해석하지 않는다.

재사용 경로는 `/mnt/working/mm-sae/runs/elice-rq1-lexicon2`, `/mnt/working/mm-sae/runs/feature-set-suite-server-2026-09-28`, `/mnt/working/mm-sae/runs/representation-diagnosis-2026-09-28`이다. 결과는 `/mnt/working/mm-sae/runs/selection-comparison-2026-09-29`에 저장한다. 분류기 기여도 계산에서는 기존 이미지 임베딩 분류기를 검증 후 재사용하고 텍스트 분류기를 추가 학습한다. 표현 진단에서 원래 임베딩·SAE 복원·전체 SAE의 분류기는 선택 기준과 무관하므로 기존 결과를 재사용한다.

각 단계는 `progress.json`에 완료 수, 경과 시간, 관측 속도에 따른 남은 시간을 기록한다. 실패한 최적화는 완료 결과로 저장하지 않는다. 결측 주석이나 흰색 가림 흔적에 대한 새로운 통제를 추가한 실험은 아니며, 기존 val을 재사용한 탐색적 후속 분석이다.

```bash
cd /mnt/working/mm-sae
PYTHONPATH=src:. .venv/bin/python -m experiments.selection_comparison.run \
  --config configs/selection-comparison-server.yaml --metric paired_mean_drop --stage prepare
PYTHONPATH=src:. .venv/bin/python -m experiments.selection_comparison.run \
  --config configs/selection-comparison-server.yaml --metric paired_mean_drop --stage suite
```

`--metric`은 `paired_mean_drop`, `single_logistic`, `probe_attribution`을 지원한다. 준비 후 기존 전체 실험은 `--stage suite`, train의 RQ1은 `--stage train_rq1`, 이미지 표현 진단은 `--stage diagnosis`로 실행한다. `pooled_auroc`의 기존 완료 결과는 직접 비교의 기준으로 재사용한다.

결과를 모으는 스크립트는 네 기준에서 평가 가능한 공통 범주와 범주 쌍의 통계를 계산한다. 같은 통계로 Matplotlib의 상자 그림을 만들어 PNG·SVG·PDF로 저장한다. 상자의 수염은 최솟값과 최댓값이며, 평균과 사분위수도 보존한다. HTML 슬라이드도 같은 통계 파일을 사용한다. 대표 공유 수는 동일한 범주 집합에서 비교하고, 같은 범주와 다른 범주의 상관점수가 동점인 쌍은 점수 초과와 분리해 기록한다.

실행 중 텍스트의 양 범주에서 분류기의 이동 거리 탐색이 비정상 종료됐다. 같은 시작점, 목적함수, 정규화 강도, 수렴 허용 오차로 탐색 재시도 한도만 100회로 늘렸을 때 정상 수렴을 확인했다. 이 재시도는 비정상 종료한 경우에만 적용한다. 성공한 기존 계산의 결과는 달라지지 않는다. 재사용한 파일의 원래 경로와 SHA-256은 결과 폴더의 `reuse_manifest.json`에 기록했고, 수정 전후 실행 코드를 함께 보존했다.
