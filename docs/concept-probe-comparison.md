# 주석 기반 특징 선택과 분류 손실을 따로 비교하는 실험

이 실험은 주석으로 학습한 특징 집합의 검색 성능이 낮았던 이유 중 두 가지를 확인한다. 기존에 고른 특징을 교체할 수 있게 만드는 효과와, 같은 특징의 가중치를 학습하는 손실을 바꾸는 효과를 각각 비교한다.

기존 조건은 개념의 존재 여부를 제곱오차 회귀로 예측한다. 특징을 하나씩 추가하고 추가할 때마다 선택된 특징의 가중치를 모두 다시 학습한다. 첫 비교는 이 조건에서 선택한 특징 하나를 미선택 특징 하나와 교환할 수 있게 한다. 모든 한 번의 교환을 평가하여 목적함수를 가장 많이 개선하는 경우를 채택한다. 한 번의 교환으로 더 개선할 수 없을 때 종료한다. 전체 특징 조합에 대한 최적해를 보장하지는 않는다.

두 번째 비교는 기존 조건에서 선택한 특징 번호를 고정하고 로지스틱 분류기를 학습한다. 특징 선택까지 로지스틱 분류기로 다시 수행하지는 않는다. 로지스틱 분류기는 개념의 존재 여부를 예측하는 분류 손실을 줄인다. 기존 제곱오차 회귀와 동일한 특징을 사용하므로, 이 비교는 가중치 학습 목표를 바꾼 효과를 확인한다.

## 공통 조건

- 기존 COCO 학습 이미지 94,630장과 연결된 캡션 473,400개를 사용한다. 이미지에는 연결된 캡션 수만큼 가중치를 부여한다.
- 이미지의 범주 존재 주석을 캡션에도 부여한다. 캡션에 적혀 있지 않은 범주도 학습 정답에 포함된다.
- 기존 SAE를 고정하고, 출력 171개를 유지한다. 개념별로 특징 8개, 16개, 32개를 사용한다.
- 특징 입력의 평균과 표준편차는 기존 대응 실험의 학습 자료에서 구한 값을 재사용한다.
- 검색에는 학습 자료에서 평균을 빼고 표준편차로 나눈 선형 출력 점수를 사용한다. 로지스틱 조건에도 확률 변환을 적용하지 않는다.
- 제곱오차 회귀와 로지스틱 분류의 가중치 벌점 계수는 0.01로 고정한다. 두 손실에 각각 최선인 계수를 찾는 실험은 아니다.
- COCO val2017 이미지 5,000장과 캡션 25,014개에서 양방향 Recall@1·5·10과 개념별 존재 구별 AUROC를 평가한다. 평가 주석은 특징 선택이나 가중치 학습에 사용하지 않는다.
- Sparse CCA는 같은 특징 수와 출력 수로 검색 성능을 비교하는 참고 조건이다. 이름 없는 출력에 주석 범주 이름을 임의로 붙여 AUROC를 계산하지 않는다.

## 실행

서버의 저장소 폴더 `/mnt/working/mm-sae`에서 다음 명령을 실행한다. 설정 파일의 모든 경로는 설정 파일이 있는 폴더를 기준으로 해석한다.

```bash
cd /mnt/working/mm-sae
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src:. \
  .venv/bin/python -m experiments.concept_probe_comparison.run \
  --config configs/concept-probe-comparison-server.yaml
```

실제 자료로 소규모 동작을 확인하려면 `--smoke-concepts 2`를 추가한다. 이 경우 첫 두 개념으로만 계산하고 별도 결과 폴더에 저장한다. 검색에는 같은 평가 이미지와 캡션을 사용하므로, 소규모 결과는 과학적 성능 비교에 사용하지 않는다.

서버 결과 폴더 `/mnt/working/mm-sae/runs/concept-probe-comparison-2026-10-05`의 `progress.json`에 현재 단계, 단계별 처리량과 남은 시간 추정치를 저장한다. 계산되지 않은 단계의 실행 시간은 추정하지 않는다. `manifest.json`은 입력과 계산 코드의 해시를 기록하며, 입력이나 계산 코드가 바뀌면 기존 폴더에 이어 실행할 수 없다. 완료된 조건은 다시 계산하지 않는다.

`report.html`에는 두 비교의 검색 표를 따로 싣는다. `summary.csv`에는 양방향 검색 수치를, `semantic_per_concept.csv`에는 개념별 AUROC를 저장한다. `fits`에는 가중치와 평균 보정값을, `diagnostics`에는 특징 교체와 로지스틱 학습의 수렴 정보를 저장한다.

반복해서 확인한 기존 평가 자료이므로, 이 결과로 최종 방법을 선택한다면 이후 별도 평가 자료에서 재확인해야 한다.
