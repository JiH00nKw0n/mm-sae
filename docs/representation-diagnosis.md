# 이미지 표현에서 개념 구별 정보가 줄어드는 위치를 확인한다

원래 CLIP 이미지 임베딩, SAE 전체 특징, 선택한 특징 5개를 같은 자료에서 비교한다. SAE가 복원한 512차원 임베딩도 비교해 압축 과정의 영향과 특징 선택의 영향을 구분한다. 이미지 인코더와 SAE는 다시 학습하지 않는다.

## 같은 자료와 분류기를 사용한다

이전 특징 집합 실험과 동일하게 COCO2017 train 이미지 118,287장을 이미지 ID 기준 학습용 94,630장과 조정용 23,657장으로 나눈다. 난수 시드는 0이다. val 이미지 5,000장에서 평가한다. 같은 이미지의 원본과 가림본은 반드시 같은 분할에 둔다. 이전 분석에서 관찰했던 val 자료이므로 독립적인 최종 확인 실험이라고 주장하지 않는다.

171개 범주를 모두 포함한다. 범주 c를 가리는 비교에는 기존에 c가 있는 것으로 주석된 이미지와 그 이미지에서 c의 픽셀을 흰색으로 가린 자료를 사용한다. 텍스트와 캡션은 사용하지 않는다. 기존 캐시를 읽으며 새 이미지 추론을 시작하지 않는다.

| 표현 | 무엇을 비교하는지 설명한다 |
|---|---|
| 원래 임베딩을 사용한다. | CLIP의 정규화된 512차원 이미지 표현에서 읽을 수 있는 정보를 측정한다. |
| SAE 복원 임베딩을 사용한다. | 전체 SAE 활성값에 기존 디코더를 적용한 512차원 표현을 사용한다. 추가 정규화를 하지 않는다. |
| SAE 전체 특징을 사용한다. | 4,096개 좌표를 사용할 수 있게 한다. 학습 입력에서 항상 0인 좌표의 계수는 0이므로 계산에서만 생략한다. |
| 선택한 특징 5개를 사용한다. | 이전 실험의 학습용 가림 AUROC 순위와 동일한 번호를 고정한다. 계수 부호를 제한하지 않아 전체 특징과 공정하게 비교한다. |
| 이전 특징 5개 점수를 유지한다. | 음수가 아닌 계수만 허용했던 기존 가림 점수를 그대로 평가해 계수 제약의 영향을 구분한다. |

각 표현에 L2 규제가 있는 로지스틱 선형 분류기를 적용한다. 표준화 통계는 학습용 원본 이미지에서 계산한다. 규제 강도는 기존과 같은 0.0001, 0.001, 0.01, 0.1, 1, 10, 100 중 조정용 로그 손실이 가장 낮은 값으로 선택한다. 평가용 AUROC로 계수 방향, 특징 번호, 규제 강도를 선택하지 않는다. 분류기만 학습하며 표현은 고정한다.

## 서로 다른 두 질문을 측정한다

**가림을 직접 학습한 분류기로 원본과 가림본의 구별 가능성을 측정한다.** 범주마다 c가 있는 원본을 1, c를 가린 이미지를 0으로 학습한다. 평가용 원본·가림 AUROC를 비교한다. 이 값이 높아도 흰색 편집 흔적을 알아본 것일 수 있으므로 의미 정보가 충분하다는 결론으로 바로 연결하지 않는다.

**가림을 보지 않은 분류기로 범주의 존재와 제거 반응을 측정한다.** 원본 이미지 전체에서 c가 있으면 1, 없으면 0으로 학습한다. 원본 평가 이미지에서 존재 판별 AUROC를 측정한다. 같은 분류기를 다시 학습하지 않고 c가 있는 원본과 c를 가린 이미지에 적용해 AUROC와 같은 이미지에서 점수가 감소한 비율을 측정한다. 전자는 두 집단 전체의 구별 정도이며 후자는 이미지별 감소 비율이므로 서로 바꾸어 해석하지 않는다.

원래 임베딩에서 학습한 존재 분류기를 SAE 복원 임베딩에 그대로 적용한 결과도 저장한다. 이것은 분류기를 다시 맞추지 않고도 원래 개념 점수가 보존되는지 확인하는 보조 분석이다.

## 결과를 다음 범위에서 해석한다

원래 임베딩과 SAE 전체 특징은 잘 구별하지만 선택한 5개만 낮다면 특징 선택 또는 적은 특징 수가 제한 요인이라는 근거가 된다. 원래 임베딩이 높고 SAE 전체가 낮다면 SAE 표현에서 선형적으로 읽을 수 있는 정보가 줄었다는 근거가 된다. 모든 표현의 가림 AUROC가 낮더라도 정보가 아예 없다고 단정하지 않는다. 선형 분류기, 표본 수, 가림 방식의 한계가 남는다.

가림 직접 학습만 높고 원본에서 학습한 존재 점수의 제거 반응은 약하다면 편집 흔적에 대한 반응과 의미에 대한 반응을 구분해야 한다. 이 실험에는 면적을 맞춘 다른 영역 가림 대조가 없으므로 객체 의미만의 인과 효과를 입증하지 않는다.

범주별 AUROC와 표현 간 차이의 불확실성은 같은 이미지의 원본·가림본을 함께 재표집해 계산한다. 기존과 같이 분류기를 재학습하지 않는 조건부 1,000회 재표집이다. 표본 수가 적은 범주도 제외하지 않고 함께 표시한다. 전체·물체·배경의 평균과 중앙값, 전체 범주 산점도를 함께 보고한다.

## 실행 결과를 보존한다

설정, 입력 파일 해시, 분할, 선택한 특징 번호, 분류기 계수, 규제 강도별 조정용 손실과 최적화 수렴 상태, 평가 점수, 범주별 표와 그림을 저장한다. 진행 상태는 10초마다 기록하며 완료한 범주를 재사용할 때 입력과 설정의 지문이 같아야 한다.

서버에서는 다음 명령으로 실행한다. GPU는 고정한 표현을 읽는 선형 분류기의 행렬 계산에만 사용한다. CPU에서도 동일한 목적함수와 최적화 알고리즘을 사용한다.

```bash
cd /mnt/working/mm-sae
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  .venv/bin/python -m experiments.representation_diagnosis.run \
  --config configs/representation-diagnosis-server.yaml
```

다음 명령으로 완료한 작업 수, 진행 중인 범주·표현·목적함수, 관측 속도에 따른 예상 남은 시간을 확인한다. 범주마다 학습 표본 수가 달라 예상 시간에는 오차가 있다.

```bash
/mnt/working/mm-sae/.venv/bin/python -m mm_sae \
  --run-dir /mnt/working/mm-sae/runs/representation-diagnosis-2026-09-28 status
```
